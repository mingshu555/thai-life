# 第 1 层：口语骨架词

构成日常句式最底层的“支柱词”，用于指出身份、存在、归属与指代。

---

### 1. เป็น
**เป็น** 表示身份、职业、属性，或表示“具备某种能力（会）”，亦可作“活着/生”的状态。
* **拼读与声调构造**：中辅音 **ป** + 短元音 **เ-ะ**（遇尾辅音变短音符 **เ-็-**）+ 清尾辅音 **น** + 无调符 = **中平调（第 1 调）**。

#### 核心用法与结构
* **表示身份、职业、性质（系动词：是）**
  - **例句**：`เขาเป็นเพื่อนผม`
    - **拆解**：`เขา` (代词：他) + `เป็น` (系动词：是) + `เพื่อน` (名词：朋友) + `ผม` (代词：我 - 男性自称)
    - **译文**：他是我的朋友。
  - **例句**：`เขาเป็นหมอ`
    - **拆解**：`เขา` (他) + `เป็น` (是) + `หมอ` (名词：医生)
    - **译文**：他是医生。
* **表示学会某种技能（动词后 + เป็น：会、懂）**
  - **例句**：`ขับรถเป็นไหม`
    - **拆解**：`ขับรถ` (动词短语：开车；`ขับ` 驾驶 + `รถ` 车) + `เป็น` (助动词：会/能) + `ไหม` (疑问助词：吗)
    - **译文**：你会开车吗？

#### 常用高频固定词组
* **ไม่เป็นไร**（没关系 / 不客气）
  - **词块拆解**：`ไม่` (不) + `เป็น` (是/成为) + `ไร` (什么；来自 `อะไร`)
  - **译文**：没关系 / 不要紧。
* **เป็นไปได้**（有可能 / 办得到）
  - **词块拆解**：`เป็น` (是) + `ไป` (去) + `ได้` (得/可以)
  - **例句**：`เป็นไปได้ไหม`
  - **拆解**：`เป็นไปได้` (有可能) + `ไหม` (吗)
  - **译文**：有可能吗？

---

### 2. คือ
**คือ** 侧重“定义、等同、即是”（A 就是 B，相当于等号）。
* **拼读与声调构造**：低辅音 **ค** + 长元音 **-ื** + 前引辅音/空辅音 **อ** + 无调符 = **中平调（第 1 调）**。

#### 核心用法与结构
* **表示定义或指示等同（系动词：就是、即是）**
  - **例句**：`นี่คืออะไร`
    - **拆解**：`นี่` (指示代词：这个) + `คือ` (系动词：是/就是) + `อะไร` (疑问代词：什么)
    - **译文**：这是什么？
  - **例句**：`นี่คือน้ำส้ม`
    - **拆解**：`นี่` (这个) + `คือ` (是) + `น้ำส้ม` (名词：橙汁；`น้ำ` 水 + `ส้ม` 橙)
    - **译文**：这是橙汁。

#### 常用高频固定词组
* **ก็คือ**（那就是... / 也就是...）
  - **词块拆解**：`ก็` (就) + `คือ` (是)
  - **例句**：`ความจริงก็คือเขาไม่รู้`
  - **拆解**：`ความจริง` (名词：真相/事实；`ความ` + `จริง` 真) + `ก็คือ` (那就是) + `เขา` (他) + `ไม่รู้` (不知道)
  - **译文**：事实就是他根本不知情。

---

### 3. มี
**มี** 表示“拥有、存在”（有）。
* **拼读与声调构造**：低辅音 **ม** + 长元音 **-ี** + 无调符 = **中平调（第 1 调）**。

#### 核心用法与结构
* **表示拥有或某处存在某物（动词：有）**
  - **例句**：`มีเงินไหม`
    - **拆解**：`มี` (动词：有) + `เงิน` (名词：钱) + `ไหม` (疑问词：吗)
    - **译文**：有钱吗？
  - **例句**：`ที่นี่มีห้องน้ำไหม`
    - **拆解**：`ที่นี่` (地点代词：这里) + `มี` (有) + `ห้องน้ำ` (名词：洗手间；`ห้อง` 房间 + `น้ำ` 水) + `ไหม` (吗)
    - **译文**：这里有洗手间吗？

#### 常用高频固定词组
* **ไม่มี**（没有）
  - **词块拆解**：`ไม่` (不) + `มี` (有)
  - **例句**：`ไม่มีปัญหา`
  - **拆解**：`ไม่มี` (没有) + `ปัญหา` (名词：问题/麻烦)
  - **译文**：没问题！
* **มีเวลา**（有空 / 有时间）
  - **词块拆解**：`มี` (有) + `เวลา` (名词：时间)
  - **例句**：`พรุ่งนี้มีเวลาไหม`
  - **拆解**：`พรุ่งนี้` (明天) + `มีเวลา` (有空) + `ไหม` (吗)
  - **译文**：明天有时间吗？

---

### 4. อยู่
**อยู่** 作实义动词为“在/居住”，作体态助词为“正在进行”或“状态持续”。
* **拼读与声调构造**：前引字 **อ** 引低辅音 **ย**（读高辅音规则）+ 长元音 **-ู** + 调符 **-่** = **低平调（第 2 调）**。

#### 核心用法与结构
* **表示动作正在进行（句末或动词后 + อยู่：正在...着）**
  - **例句**：`ทำอะไรอยู่`
    - **拆解**：`ทำ` (动词：做) + `อะไร` (代词：什么) + `อยู่` (进行助词：着/处于进行中)
    - **译文**：你正在做什么呢？
  - **例句**：`เขากำลังอ่านหนังสืออยู่`
    - **拆解**：`เขา` (他) + `กำลัง` (副词：正) + `อ่าน` (读) + `หนังสือ` (书) + `อยู่` (助词：着)
    - **译文**：他正在看书。
* **表示状态依然持续（ยัง + 动词 + อยู่：还在...）**
  - **例句**：`ยังจำได้อยู่`
    - **拆解**：`ยัง` (副词：还/仍旧) + `จำได้` (记得) + `อยู่` (助词：依然)
    - **译文**：依然还记得。
* **实义动词：居住、位于某处（在、住）**
  - **例句**：`อยู่ที่ไหน`
    - **拆解**：`อยู่` (动词：在/位于) + `ที่ไหน` (疑问代词：在哪里)
    - **译文**：在哪里？

#### 常用高频固定词组
* **อยู่ดีๆ**（好端端地 / 忽然间）
  - **词块拆解**：`อยู่` (处于) + `ดีๆ` (好好的)
  - **例句**：`อยู่ดีๆ ก็ร้องไห้`
  - **拆解**：`อยู่ดีๆ` (好端端地) + `ก็` (就) + `ร้องไห้` (动词短语：哭泣；`ร้อง` 叫 + `ไห้` 哭)
  - **译文**：好端端地突然就哭了。
* **ไม่อยู่**（不在）
  - **词块拆解**：`ไม่` (不) + `อยู่` (在)
  - **例句**：`เขาไม่อยู่บ้าน`
  - **拆解**：`เขา` (他) + `ไม่อยู่` (不在) + `บ้าน` (家)
  - **译文**：他不在家。

### 5. นี่ / นั่น / โน่น
用于独立充当主语或宾语的独立指示代词（这 / 那 / 远处那）。
* **拼读与声调构造**：
  - `นี่`：低辅音 **น** + 长元音 **-ี** + 调符 **-่** = **降调（第 3 调）**。
  - `นั่น`：低辅音 **น** + 短元音 **-ะ**（变体 **-ั-**）+ 清尾 **น** + 调符 **-่** = **降调（第 3 调）**。
  - `โน่น`：低辅音 **น** + 长元音 **โ-** + 清尾 **น** + 调符 **-่** = **降调（第 3 调）**。

#### 核心用法与结构
* **例句**：`นี่ของใคร`
  - **拆解**：`นี่` (独立代词：这个) + `ของ` (所属助词：...的) + `ใคร` (疑问代词：谁)
  - **译文**：这是谁的？
* **例句**：`นั่นอะไร`
  - **拆解**：`นั่น` (独立代词：那个) + `อะไร` (疑问代词：什么)
  - **译文**：那是什么？

#### 常用高频固定词组
* **นี่ไง**（在这儿呢 / 这不就是嘛）
  - **词块拆解**：`นี่` (这) + `ไง` (看吧/就是)
  - **译文**：你看，就在这儿呀！

---

### 6. นี้ / นั้น / โน้น
置于名词或量词之后充当后置修饰限定的指示词（这个 / 那个 / 远处那个）。
* **拼读与声调构造**：
  - `นี้`：低辅音 **น** + 长元音 **-ี** + 调符 **-้** = **高平调（第 4 调）**。
  - `นั้น`：低辅音 **น** + 短元音 **-ะ**（变体 **-ั-**）+ 清尾 **น** + 调符 **-้** = **高平调（第 4 调）**。
  - `โน้น`：低辅音 **น** + 长元音 **โ-** + 清尾 **น** + 调符 **-้** = **高平调（第 4 调）**。

#### 核心用法与结构
* **例句**：`คนนี้เป็นใคร`
  - **拆解**：`คน` (名词/量词：人) + `นี้` (后置指示：这) + `เป็น` (是) + `ใคร` (谁)
  - **译文**：这个人是谁？
* **例句**：`อันนั้นเท่าไหร่`
  - **拆解**：`อัน` (量词：个) + `นั้น` (那) + `เท่าไหร่` (多少钱)
  - **译文**：那个多少钱？

#### 常用高频固定词组
* **ตอนนี้**（现在 / 这个时候）
  - **词块拆解**：`ตอน` (时候/期间) + `นี้` (这)
  - **例句**：`ตอนนี้หิวมาก`
  - **拆解**：`ตอนนี้` (现在) + `หิว` (饿) + `มาก` (非常)
  - **译文**：现在肚子很饿。
* **แค่นี้**（就这么点 / 仅此）
  - **词块拆解**：`แค่` (仅/只) + `นี้` (这)
  - **译文**：就这些 / 仅此而已。

---

# 第 2 层：口语疑问与否定词

日常口语交互中最核心的“一问一答”系统。

---

### 7. อะไร
**อะไร** 是日常提问使用频率最高的疑问代词（什么）。
* **拼读与声调构造**：
  - `อะ`：中辅音 **อ** + 短元音 **-ะ** = 低平调。
  - `ไร`：低辅音 **ร** + 特殊短元音 **ไ-** = 中平调。整体读作轻重组合。

#### 核心用法与结构
* **例句**：`กินอะไรดี`
  - **拆解**：`กิน` (动词：吃) + `อะไร` (代词：什么) + `ดี` (形容词：好)
  - **译文**：吃什么好呢？
* **例句**：`ทำอะไรอยู่`
  - **拆解**：`ทำ` (做) + `อะไร` (什么) + `อยู่` (进行助词：着)
  - **译文**：正在干嘛呢？

#### 常用高频固定词组
* **อะไรนะ**（什么？/ 再说一遍？）
  - **词块拆解**：`อะไร` (什么) + `นะ` (语气词)
  - **译文**：你说什么？（没听清时反问）。
* **อะไรก็ได้**（什么都行 / 随便）
  - **词块拆解**：`อะไร` (什么) + `ก็` (就) + `ได้` (行/可以)
  - **例句**：`กินอะไรก็ได้`
  - **拆解**：`กิน` (吃) + `อะไรก็ได้` (什么都行)
  - **译文**：吃什么都可以。

---

### 8. ที่ไหน / ตรงไหน
用于提问地点与具体方位（在哪里 / 在哪个位置）。
* **拼读与声调构造**：
  - `ที่`（降调）+ `ไหน`（高辅音 **ห** 前引低辅音 **น** + 特殊短元音 **ไ-** = 升调）。
  - `ตรง`（中辅音连缀清尾 = 中平调）+ `ไหน`（升调）。

#### 核心用法与结构
* **例句**：`ห้องน้ำอยู่ที่ไหน`
  - **拆解**：`ห้องน้ำ` (洗手间；`ห้อง` 房 + `น้ำ` 水) + `อยู่` (在) + `ที่ไหน` (在哪里)
  - **译文**：洗手间在哪里？
* **例句**：`เจ็บตรงไหน`
  - **拆解**：`เจ็บ` (动词：疼/痛) + `ตรงไหน` (疑问方位：哪个位置；`ตรง` 处/位置 + `ไหน` 哪)
  - **译文**：哪里疼？/ 伤在哪个部位？

---

### 9. เมื่อไหร่ / กี่โมง
提问时间与钟点（什么时候 / 几点）。
* **拼读与声调构造**：
  - `เมื่อ`（降调）+ `ไหร่`（低平调）。
  - `กี่`（中辅音 + 一调符 = 低平调）+ `โมง`（低辅音 + 长元音 + 清尾 = 中平调）。

#### 核心用法与结构
* **例句**：`จะไปเมื่อไหร่`
  - **拆解**：`จะ` (将要) + `ไป` (去) + `เมื่อไหร่` (什么时候)
  - **译文**：什么时候出发/去？
* **例句**：`ตอนนี้กี่โมงแล้ว`
  - **拆解**：`ตอนนี้` (现在) + `กี่โมง` (几点；`กี่` 几 + `โมง` 钟点) + `แล้ว` (了)
  - **译文**：现在几点钟了？

---

### 10. ใคร
疑问代词：谁。
* **拼读与声调构造**：中辅音 **ค**（低辅音）与 **ร** 复合连缀 + 特殊短元音 **ใ-** = **中平调（第 1 调）**。

#### 核心用法与结构
* **例句**：`เขาเป็นใคร`
  - **拆解**：`เขา` (他) + `เป็น` (是) + `ใคร` (谁)
  - **译文**：他是谁？
* **例句**：`ไปกับใคร`
  - **拆解**：`ไป` (去) + `กับ` (介词：和/跟) + `ใคร` (谁)
  - **译文**：跟谁一起去？

#### 常用高频固定词组
* **ใครก็ได้**（谁都可以 / 任何人）
  - **词块拆解**：`ใคร` (谁) + `ก็` (就) + `ได้` (行)
  - **译文**：谁都行。

---

### 11. ทำไม
疑问代词：为什么。
* **拼读与声调构造**：中辅音 **ท**（低辅音）+ 特殊短元音 **ำ** = 中平调；`ไม`（低辅音 + 特殊短元音 **ไ-**）= 中平调。

#### 核心用法与结构
* **例句**：`ทำไมไม่มา`
  - **拆解**：`ทำไม` (为什么) + `ไม่` (不) + `มา` (来)
  - **译文**：为什么没来？
* **例句**：`ทำไมถึงรู้`
  - **拆解**：`ทำไม` (为什么) + `ถึง` (助词：竟然/得以) + `รู้` (动词：知道)
  - **译文**：你怎么会知道的？

---

### 12. ยังไง
口语中最常用的“怎么、如何”（书面语写作 `อย่างไร`）。
* **拼读与声调构造**：`ยัง`（中平调）+ `ไง`（中平调）。

#### 核心用法与结构
* **例句**：`อันนี้ทำยังไง`
  - **拆解**：`อันนี้` (这个) + `ทำ` (做) + `ยังไง` (怎么/如何)
  - **译文**：这个怎么做？
* **例句**：`ไปสยามยังไง`
  - **拆解**：`ไป` (去) + `สยาม` (暹罗 Siam) + `ยังไง` (怎么去)
  - **译文**：去暹罗广场怎么走？

#### 常用高频固定词组
* **เป็นยังไงบ้าง**（近来如何？/ 感觉怎么样？）
  - **词块拆解**：`เป็น` (是/处于) + `ยังไง` (怎样) + `บ้าง` (些许)
  - **译文**：最近怎么样？/ 事情进展如何？

---

### 13. เท่าไหร่ / กี่
询问价格或数量（多少钱 / 多少个）。
* **拼读与声调构造**：
  - `เท่า`（降调）+ `ไหร่`（低平调）。
  - `กี่`（低平调）。

#### 核心用法与结构
* **例句**：`ทั้งหมดเท่าไหร่`
  - **拆解**：`ทั้งหมด` (全部/总共；`ทั้ง` 全 + `หมด` 完) + `เท่าไหร่` (多少钱)
  - **译文**：一共多少钱？
* **例句**：`มีกี่คน`
  - **拆解**：`มี` (有) + `กี่` (几) + `คน` (人/位)
  - **译文**：有几位？

---

### 14. อันไหน / คนไหน
选择疑问词（哪一个 / 哪个人）。
* **拼读与声调构造**：量词 + `ไหน`（升调）。

#### 核心用法与结构
* **例句**：`ชอบอันไหน`
  - **拆解**：`ชอบ` (喜欢) + `อันไหน` (哪一个；`อัน` 个 + `ไหน` 哪)
  - **译文**：喜欢哪一个？
* **例句**：`คนไหนเป็นแฟนคุณ`
  - **拆解**：`คนไหน` (哪个人) + `เป็น` (是) + `แฟน` (男女朋友/对象) + `คุณ` (你)
  - **译文**：哪一位是你的对象？

---

### 15. ไหม / มั้ย
句末疑问助词：吗？（口语中极高频读作高平调 `มั้ย`）。
* **拼读与声调构造**：高辅音 **ห** 引低辅音 **ม** + 特殊短元音 **ไ-** = **升调（第 5 调）**；口语常音变为高平调 `มั้ย`。

#### 核心用法与结构
* **例句**：`เผ็ดไหม`
  - **拆解**：`เผ็ด` (形容词：辣) + `ไหม` (疑问词：吗)
  - **译文**：辣吗？
* **例句**：`ชอบมั้ย`
  - **拆解**：`ชอบ` (喜欢) + `มั้ย` (口语：吗)
  - **译文**：喜欢吗？

---

### 16. หรือยัง / ยัง
句末时态疑问助词：...了吗？/ 还没吗？
* **拼读与声调构造**：`หรือ`（升调）+ `ยัง`（中平调）。

#### 核心用法与结构
* **例句**：`กินข้าวหรือยัง`
  - **拆解**：`กินข้าว` (吃饭) + `หรือยัง` (了没有)
  - **译文**：吃饭了吗？
* **例句**：`ถึงหรือยัง`
  - **拆解**：`ถึง` (到达) + `หรือยัง` (到了没)
  - **译文**：到了没有？

#### 常用口语回答
* **กินแล้ว**（吃过了）
* **ยังไม่ได้กิน / ยัง**（还没吃 / 还没）

---

### 17. ใช่ไหม / ใช่มั้ย
句末确认疑问助词：对吧？/ 是不是？
* **拼读与声调构造**：`ใช่`（降调）+ `ไหม`（升调）/ `มั้ย`（高平调）。

#### 核心用法与结构
* **例句**：`คุณเป็นคนจีนใช่ไหม`
  - **拆解**：`คุณ` (你) + `เป็น` (是) + `คนจีน` (中国人；`คน` 人 + `จีน` 中国) + `ใช่ไหม` (对吧/是不是)
  - **译文**：你是中国人对吧？

---

### 18. หรือเปล่า / ป่าว
句末选择疑问助词：是不是？/ 没有吗？（口语极常弱读为 `ป่าว`）。
* **拼读与声调构造**：`หรือ`（升调）+ `เปล่า`（低平调）；口语简化写作 `ป่าว`（低平调）。

#### 核心用法与结构
* **例句**：`จริงป่าว`
  - **拆解**：`จริง` (形容词：真/确实) + `ป่าว` (口语疑问：吗/是不是；来自 `หรือเปล่า`)
  - **译文**：真的假的？/ 是真的吗？
* **例句**：`โกรธหรือเปล่า`
  - **拆解**：`โกรธ` (动词：生气) + `หรือเปล่า` (是不是)
  - **译文**：生气了吗？

---

### 19. ไม่
基本否定副词：不、没（直接置于动词或形容词前）。
* **拼读与声调构造**：低辅音 **ม** + 特殊短元音 **ไ-** + 调符 **-่** = **降调（第 3 调）**。

#### 核心用法与结构
* **例句**：`ไม่กิน`
  - **拆解**：`ไม่` (不) + `กิน` (吃)
  - **译文**：不吃。
* **例句**：`ไม่แพง`
  - **拆解**：`ไม่` (不) + `แพง` (贵)
  - **译文**：不贵。

---

### 20. ไม่ได้
过去未发生否定（没有做）或能力许可否定（不能）。
* **拼读与声调构造**：`ไม่` (降调) + `ได้` (降调)。

#### 核心用法与结构
* **例句**：`เมื่อวานไม่ได้ไป`
  - **拆解**：`เมื่อวาน` (昨天) + `ไม่ได้` (过去否定：没/没有) + `ไป` (去)
  - **译文**：昨天没有去。
* **例句**：`ทำไม่ได้`
  - **拆解**：`ทำ` (做) + `ไม่ได้` (后置能力否定：不能/做不到)
  - **译文**：做不到 / 做不来。

---

### 21. 不要 / อย่า
祈使句劝阻：别、不要。
* **拼读与声调构造**：前引字 **อ** 引低辅音 **ย** + 长元音 **-า** + 调符 **-่** = **低平调（第 2 调）**。

#### 核心用法与结构
* **例句**：`อย่าคิดมาก`
  - **拆解**：`อย่า` (别) + `คิดมาก` (想太多；`คิด` 想 + `มาก` 多)
  - **译文**：别想太多了。
* **例句**：`อย่าเพิ่งไป`
  - **拆解**：`อย่า` (别) + `เพิ่ง` (刚/先) + `ไป` (走/去)
  - **译文**：先别走。

---

### 22. ห้าม
硬性禁止命令：严禁、禁止。
* **拼读与声调构造**：高辅音 **ห** + 长元音 **-า** + 清尾辅音 **ม** + 调符 **-้** = **降调（第 3 调）**。

#### 核心用法与结构
* **例句**：`ห้ามสูบบุหรี่`
  - **拆解**：`ห้าม` (严禁) + `สูบบุหรี่` (动词短语：吸烟；`สูบ` 吸 + `บุหรี่` 香烟)
  - **译文**：禁止吸烟。
* **例句**：`ห้ามจอดรถ`
  - **拆解**：`ห้าม` (禁止) + `จอดรถ` (停车；`จอด` 停 + `รถ` 车)
  - **译文**：严禁停车。

---

### 23. ไม่ต้อง
情态否定词：不用、不必。
* **拼读与声调构造**：`ไม่` (降调) + `ต้อง` (降调)。

#### 核心用法与结构
* **例句**：`ไม่ต้องรีบ`
  - **拆解**：`ไม่ต้อง` (不用/不必) + `รีบ` (赶/着急)
  - **译文**：不用着急。
* **例句**：`ไม่ต้องเกรงใจ`
  - **拆解**：`ไม่ต้อง` (不用) + `เกรงใจ` (客气；`เกรง` 畏 + `ใจ` 心)
  - **译文**：不用客气 / 别见外。

---

### 24. 不怎么 / ไม่ค่อย
程度否定副词：不太...、不怎么...
* **拼读与声调构造**：`ไม่` (降调) + `ค่อย` (降调)。

#### 核心用法与结构
* **例句**：`วันนี้ไม่ค่อยสบาย`
  - **拆解**：`วันนี้` (今天) + `ไม่ค่อย` (不太/不怎么) + `สบาย` (舒服/健康)
  - **译文**：今天身体不太舒服。
* **例句**：`ไม่ค่อยชอบ`
  - **拆解**：`ไม่ค่อย` (不怎么) + `ชอบ` (喜欢)
  - **译文**：不大喜欢。

---

# 第 3 层：口语时态、体态与助动词

掌握动作发生的时间感、状态演变与主观意图。

---

### 25. จะ
**จะ** 置于动词前，表示说话人的计划、意图与将来时态（将要、打算、会）。
* **拼读与声调构造**：中辅音 **จ** + 短元音 **-ะ**（中辅音 + 死音节）= **低平调（第 2 调）**。

#### 核心用法与结构
* **表示将来意图或计划（将要、打算、会）**
  - **例句**：`พรุ่งนี้จะไปเที่ยว`
    - **拆解**：`พรุ่งนี้` (明天) + `จะ` (助动词：打算/将要) + `ไปเที่ยว` (动词短语：去玩/旅游)
    - **译文**：明天打算去玩。
  - **例句**：`ฉันจะไม่ลืมคุณ`
    - **拆解**：`ฉัน` (我) + `จะ` (会) + `ไม่` (不) + `ลืม` (忘记) + `คุณ` (你)
    - **译文**：我不会忘记你的。
* **表示推测与估计（常与 `คง` 连用：大概会...）**
  - **例句**：`คงจะดี`
    - **拆解**：`คง` (副词：大概/也许) + `จะ` (会) + `ดี` (好)
    - **译文**：大概会挺好吧。

#### 常用高频固定词组
* **จะไป**（要去 / 打算去）
  - **词块拆解**：`จะ` (将要) + `ไป` (去)
  - **例句**：`จะ去哪` -> `จะไปไหน`
  - **拆解**：`จะไป` (要去) + `ไหน` (哪里)
  - **译文**：打算去哪里？
* **จะไม่**（绝不会...）
  - **词块拆解**：`จะ` (会) + `ไม่` (不)
  - **例句**：`จะไม่ทำอีกแล้ว`
  - **拆解**：`จะไม่ทำ` (绝不会做) + `อีกแล้ว` (再...了)
  - **译文**：我再也不会这么做了。

---

### 26. กำลัง...อยู่
正在进行时体态框架（正在...着）。口语中可单用 `กำลัง`，或单用句末 `อยู่`。
* **拼读与声调构造**：
  - `กำ`（中平调）+ `ลัง`（中平调）。
  - `อยู่`（低平调）。

#### 核心用法与结构
* **例句**：`เขากำลังกินข้าวอยู่`
  - **拆解**：`เขา` (他) + `กำลัง` (正) + `กินข้าว` (吃饭) + `อยู่` (着)
  - **译文**：他正在吃饭呢。

---

### 27. แล้ว
**แล้ว** 是时态标记与承接连词，日常口语中表达动作完毕、顺接或话题转换。
* **拼读与声调构造**：低辅音 **ล** + 长元音 **แ-** + 清尾辅音 **ว** + 调符 **-้**（低辅音 + 二调符）= **高平调（第 4 调）**。

#### 核心用法与结构
* **表示动作已经完成（体态助词，放句末：...了）**
  - **例句**：`เข้าใจแล้ว`
    - **拆解**：`เข้าใจ` (动词：理解/明白；`เข้า` 进 + `ใจ` 心) + `แล้ว` (助词：已经/了)
    - **译文**：已经明白了。
  - **例句**：`กินข้าวแล้ว`
    - **拆解**：`กิน` (吃) + `ข้าว` (饭) + `แล้ว` (了)
    - **译文**：吃过饭了。
* **表示时间的先后顺承（连词：然后、随后）**
  - **例句**：`อาบน้ำแล้วค่อยนอน`
    - **拆解**：`อาบน้ำ` (洗澡) + `แล้ว` (连词：然后) + `ค่อย` (副词：才/再) + `นอน` (睡觉)
    - **译文**：洗完澡后再去睡觉。
* **用于句首，表示话题转换或追问（连词：那、那么）**
  - **例句**：`แล้วคุณล่ะ`
    - **拆解**：`แล้ว` (连词：那么/那) + `คุณ` (代词：你/您) + `ล่ะ` (疑问语气词：呢)
    - **译文**：那，你呢？

#### 常用高频固定词组
* **แล้วก็**（然后、还有）
  - **词块拆解**：`แล้ว` (随后) + `ก็` (就/又)
  - **例句**：`ซื้อข้าวแล้วก็ซื้อน้ำ`
  - **拆解**：`ซื้อข้าว` (买饭) + `แล้วก็` (然后还) + `ซื้อน้ำ` (买水)
  - **译文**：买了饭，然后还买了水。
* **แล้วไง**（那又怎样？/ 那又如何？）
  - **词块拆解**：`แล้ว` (那么) + `ไง` (怎样/如何)
  - **译文**：那又怎样？（熟人口语，略带不在乎语气）。
* **นานแล้ว**（好久了 / 很久以前）
  - **词块拆解**：`นาน` (久/长时间) + `แล้ว` (已经)
  - **译文**：很久之前了。

### 28. เคย
经验时态助动词：曾经、做过某事（过）。
* **拼读与声调构造**：低辅音 **ค** + 复合元音 **เ-อ**（遇尾辅音省略变形）+ 清尾辅音 **ย** = **中平调（第 1 调）**。

#### 核心用法与结构
* **例句**：`เคยไปเมืองไทยไหม`
  - **拆解**：`เคย` (助动词：曾经/过) + `ไป` (去) + `เมืองไทย` (泰国；`เมือง` 城/国 + `ไทย` 泰) + `ไหม` (吗)
  - **译文**：你去过泰国吗？
* **例句**：`ไม่เคยเห็น`
  - **拆解**：`ไม่เคย` (从没/未曾；`ไม่` + `เคย`) + `เห็น` (动词：看见/见到)
  - **译文**：从来没见过。

### 29. เพิ่ง / เพิ่งจะ
时间副词：刚、刚刚（动作刚发生不久）。
* **拼读与声调构造**：低辅音 **พ** + 结合短元音 **-ึ** + 清尾辅音 **ง** + 调符 **-่** = **降调（第 3 调）**。

#### 核心用法与结构
* **例句**：`ผมเพิ่งมาถึง`
  - **拆解**：`ผม` (我) + `เพิ่ง` (副词：刚刚) + `มาถึง` (复合动词：到达；`มา` 来 + `ถึง` 到)
  - **译文**：我刚到。
* **例句**：`เพิ่งรู้เรื่อง`
  - **拆解**：`เพิ่ง` (刚刚) + `รู้` (知道) + `เรื่อง` (事情/情况)
  - **译文**：刚刚才得知这件事。

### 30. ไว้
**ไว้** 核心语义为“放置/留存”，作补语时表示“预先准备”或“状态保持”。
* **拼读与声调构造**：低辅音 **ว** + 特殊短元音 **ไ-** + 调符 **-้**（低辅音 + 二调符）= **高平调（第 4 调）**。

#### 核心用法与结构
* **表示提前做好准备（动词 + ไว้：预先做好...）**
  - **例句**：`จองโต๊ะไว้แล้ว`
    - **拆解**：`จอง` (动词：预订) + `โต๊ะ` (名词：桌子) + `ไว้` (助词：预先留存) + `แล้ว` (助词：已经)
    - **译文**：已经提前订好位子了。
  - **例句**：`คิดไว้ก่อน`
    - **拆解**：`คิด` (动词：想/思考) + `ไว้` (助词：预先存着) + `ก่อน` (副词：先)
    - **译文**：先提前想好。
* **表示状态的保持与留存（动词 + ไว้：保持住、存着）**
  - **例句**：`เปิดไฟไว้`
    - **拆解**：`เปิด` (动词：打开) + `ไฟ` (名词：灯) + `ไว้` (助词：保持状态不变)
    - **译文**：开着灯（让灯一直亮着）。
  - **例句**：`จำไว้ให้ดี`
    - **拆解**：`จำ` (动词：记/记住) + `ไว้` (助词：牢存) + `ให้ดี` (副词短语：好好地；`ให้` 使之 + `ดี` 好)
    - **译文**：牢牢记在心里。

#### 常用高频固定词组
* **เอาไว้**（留着 / 存下）
  - **词块拆解**：`เอา` (拿/取) + `ไว้` (存留)
  - **例句**：`เอาไว้ที่นี่`
  - **拆解**：`เอาไว้` (放在/留着) + `ที่นี่` (这里)
  - **译文**：放在这里。
* **เอาไว้ก่อน**（先搁一边 / 以后再说）
  - **词块拆解**：`เอาไว้` (放着) + `ก่อน` (先)
  - **译文**：先搁置一下 / 以后再谈。
* **เก็บไว้**（收好 / 收藏）
  - **词块拆解**：`เก็บ` (收/藏) + `ไว้` (存好)
  - **例句**：`เก็บไว้ในกระเป๋า`
  - **拆解**：`เก็บไว้` (收好) + `ใน` (在...里) + `กระเป๋า` (包/口袋)
  - **译文**：收好放在包里。

### 31. ซะ / เสีย
**ซะ**（口语）/ **เสีย**（书面）表示动作彻底完成，带催促或惋惜语气。
* **拼读与声调构造**：低辅音 **ซ** + 短元音 **-ะ**（低辅音 + 死音节）= **高平调（第 4 调）**。

#### 核心用法与结构
* **句末口语催促、建议（动词 + ซะ：赶紧...吧）**
  - **例句**：`รีบกินซะ`
    - **拆解**：`รีบ` (副词：赶紧/赶快) + `กิน` (动词：吃) + `ซะ` (语气助词：赶紧...吧)
    - **译文**：赶紧吃吧！
  - **例句**：`รีบไปซะ`
    - **拆解**：`รีบ` (赶快) + `ไป` (去) + `ซะ` (去吧)
    - **译文**：赶快去吧！
* **表示无可挽回的损失与惋惜（动词 + เสียแล้ว / ซะแล้ว）**
  - **例句**：`ทำโทรศัพท์หายเสียแล้ว`
    - **拆解**：`ทำ` (做/弄) + `โทรศัพท์` (名词：手机) + `หาย` (动词：丢失) + `เสียแล้ว` (语气助词短语：掉了/遗憾完成)
    - **译文**：把手机弄丢了。
  - **例句**：`สายซะแล้ว`
    - **拆解**：`สาย` (形容词：迟到/晚) + `ซะแล้ว` (助词短语：已经...了/太迟了)
    - **译文**：已经迟了 / 太迟了。

#### 常用高频固定词组
* **เสียใจ**（伤心 / 难过 / 抱歉）
  - **词块拆解**：`เสีย` (坏/失去) + `ใจ` (心)
  - **例句**：`เสียใจด้วยนะ`
  - **拆解**：`เสียใจ` (难过/感到遗憾) + `ด้วย` (也/一同) + `นะ` (语气词)
  - **译文**：请节哀 / 替你感到难过。
* **เสียดาย**（可惜 / 惋惜）
  - **词块拆解**：`เสีย` (损失) + `ดาย` (白白地)
  - **例句**：`น่าเสียดายจัง`
  - **拆解**：`น่าเสียดาย` (真可惜；`น่า` 值得/让人生出 + `เสียดาย` 可惜) + `จัง` (副词：真/非常)
  - **译文**：真可惜呀！

### 32. ได้
**ได้** 是多功能超级动词，位置不同，含义完全不同。
* **拼读与声调构造**：中辅音 **ด** + 特殊短元音 **ไ-** + 调符 **-้** = **降调（第 3 调）**。

#### 核心用法与结构
* **表示能力、许可、结果（动词后 + ได้：能、可以）**
  - **例句**：`พูดภาษาไทยได้`
    - **拆解**：`พูด` (动词：说) + `ภาษาไทย` (名词：泰语；`ภาษา` 语言 + `ไทย` 泰国) + `ได้` (助动词：能/会)
    - **译文**：会说泰语 / 能说泰语。
  - **例句**：`ไปได้ไหม`
    - **拆解**：`ไป` (去) + `ได้ไหม` (可以吗；`ได้` 可以 + `ไหม` 吗)
    - **译文**：可以去吗？
* **表示过去发生、得以实现（`ได้` / `ไม่ได้` + 动词前：曾经、没有）**
  - **例句**：`เมื่อวานไม่ได้ไป`
    - **拆解**：`เมื่อวาน` (时间词：昨天) + `ไม่ได้` (否定过去：没有) + `ไป` (去)
    - **译文**：昨天没有去。
  - **例句**：`ได้ยินเสียงไหม`
    - **拆解**：`ได้ยิน` (复合动词：听见；`ได้` 得 + `ยิน` 听闻) + `เสียง` (名词：声音) + `ไหม` (吗)
    - **译文**：听到声音了吗？
* **实义动词：获得、得到（动词 + 宾语）**
  - **例句**：`ได้รางวัล`
    - **拆解**：`ได้` (动词：得到) + `รางวัล` (名词：奖项/奖品)
    - **译文**：获得了奖品。

#### 常用高频固定词组
* **ก็ได้**（也行 / 都可以——表达妥协）
  - **词块拆解**：`ก็` (就) + `ได้` (可以)
  - **例句**：`กินอะไรก็ได้`
  - **拆解**：`กิน` (吃) + `อะไรก็ได้` (代词短语：什么都行；`อะไร` 什么 + `ก็` 就 + `ได้` 行)
  - **译文**：吃什么都行。
* **จำได้**（记得 / 想得起来）
  - **词块拆解**：`จำ` (记) + `ได้` (得/成功记住)
  - **例句**：`ยังจำได้ไหม`
  - **拆解**：`ยัง` (还) + `จำได้` (记得) + `ไหม` (吗)
  - **译文**：还记得吗？

### 33. ต้อง
强情态动词：必须、得（做某事）。
* **拼读与声调构造**：中辅音 **ต** + 元音 **-อ-** + 清尾辅音 **ง** + 调符 **-้** = **降调（第 3 调）**。

#### 核心用法与结构
* **例句**：`ต้องรีบไป`
  - **拆解**：`ต้อง` (必须/得) + `รีบ` (赶快) + `ไป` (去)
  - **译文**：必须得快点去了。
* **例句**：`ต้องทำยังไง`
  - **拆解**：`ต้อง` (应该/需要) + `ทำ` (做) + `ยังไง` (怎么)
  - **译文**：该怎么做呢？

### 34. น่า / น่าจะ
推测助动词或形容词前缀：应该、大概会 / 令人...、值得...
* **拼读与声调构造**：低辅音 **น** + 长元音 **-า** + 调符 **-่** = **降调（第 3 调）**。

#### 核心用法与结构
* **例句**：`น่ารักมาก`
  - **拆解**：`น่า` (令人/生出...) + `รัก` (爱) + `มาก` (非常)
  - **译文**：非常可爱。
* **例句**：`เขาน่าจะมา`
  - **拆解**：`เขา` (他) + `น่าจะ` (推测：大概会/应该会) + `มา` (来)
  - **译文**：他大概会来。

### 35. อยาก / อยากได้
意愿动词：想（后接动词）/ 想要（后接名词）。
* **拼读与声调构造**：前引字 **อ** 引低辅音 **ย** + 长元音 **-า** + 浊尾辅音 **ก** = **低平调（第 2 调）**。

#### 核心用法与结构
* **例句**：`อยากไปเที่ยว`
  - **拆解**：`อยาก` (想) + `ไปเที่ยว` (动词短语：去旅游)
  - **译文**：想去旅游。
* **例句**：`อยากได้อันนี้`
  - **拆解**：`อยากได้` (想要；`อยาก` 想 + `ได้` 得) + `อันนี้` (名词代词：这个)
  - **译文**：我想要这个。

### 36. ขอ
礼貌索取动词：请给我... / 允许我...
* **拼读与声调构造**：高辅音 **ข** + 元音 **-อ-** + 无调符 = **升调（第 5 调）**。

#### 核心用法与结构
* **例句**：`ขอน้ำเปล่าหนึ่งแก้ว`

  - **译文**：麻烦给一杯清水。
* **例句**：`ขอดูหน่อย`
  - **拆解**：`ขอ` (允许/求取) + `ดู` (看) + `หน่อย` (一下)
  - **译文**：请让我看一下。

### 37. ช่วย

  - **译文**：麻烦帮忙关一下门。
* **例句**：`ช่วยด้วย`
  - **拆解**：`ช่วย` (救/帮) + `ด้วย` (助词：救命/帮帮忙)
  - **译文**：救命！/ 帮帮我！

### 38. ลอง

# 第 4 层：口语介词、从句与使役结构

单词与分句之间的黏合剂、从句引导与使役受损结构。

### 39. ที่
**ที่** 是泰语中使用最广的词，涵盖定语关系代词（...的）、地点介词（在）与序数词前缀（第）。
* **拼读与声调构造**：低辅音 **ท** + 长元音 **-ี** + 调符 **-่** = **降调（第 3 调）**。

#### 核心用法与结构
* **定语从句关系代词（...的，修饰名词）**
  - **例句**：`คนที่ยืนอยู่ตรงนั้น`
    - **拆解**：`คน` (名词：人) + `ที่` (关系连词：...的) + `ยืน` (动词：站) + `อยู่` (进行助词：着) + `ตรงนั้น` (方位词短语：那儿；`ตรง` 在/处 + `นั้น` 那)
    - **译文**：站在那里的那个人。
* **介词：在某地（在）**
  - **例句**：`กินข้าวที่บ้าน`
    - **拆解**：`กินข้าว` (动词短语：吃饭) + `ที่` (介词：在) + `บ้าน` (名词：家)
    - **译文**：在家里吃饭。
* **序数词前缀：第...**
  - **例句**：`ครั้งที่หนึ่ง`
    - **拆解**：`ครั้ง` (量词：次/回) + `ที่` (序数词前缀：第) + `หนึ่ง` (数词：一)
    - **译文**：第一次。

#### 常用高频固定词组
* **ที่นี่ / ที่นั่น**（这里 / 那里）
* **ที่ดีที่สุด**（最好的；`ที่` + `ดี` 好 + `ที่สุด` 最）

---

### 40. ของ
**ของ** 表示定语所属关系（...的），亦可作为名词“东西/物品”。
* **拼读与声调构造**：高辅音 **ข** + 元音 **-อ-** + 清尾辅音 **ง** = **升调（第 5 调）**。

#### 核心用法与结构
* **结构助词：...的（所属物 + ของ + 所有人）**
  - **例句**：`กระเป๋าของฉัน`
    - **拆解**：`กระเป๋า` (名词：包/皮包) + `ของ` (助词：...的) + `ฉัน` (代词：我)
    - **译文**：我的包。
  - **例句**：`นี่ของใคร`
    - **拆解**：`นี่` (指示代词：这个) + `ของ` (助词：...的) + `ใคร` (疑问代词：谁)
    - **译文**：这是谁的？
* **名词：东西、物品**
  - **例句**：`ไปซื้อของ`
    - **拆解**：`ไป` (去) + `ซื้อ` (买) + `ของ` (名词：东西/物品)
    - **译文**：去买东西 / 逛街购物。
  - **例句**：`เก็บของ`
    - **拆解**：`เก็บ` (动词：收拾/收纳) + `ของ` (名词：东西)
    - **译文**：收拾东西。

#### 常用高频固定词组
* **ของกิน**（吃食 / 美食）
  - **词块拆解**：`ของ` (东西) + `กิน` (吃)
  - **例句**：`มีของกินเยอะมาก`
  - **拆解**：`มี` (有) + `ของกิน` (吃的东西) + `เยอะมาก` (非常多；`เยอะ` 多 + `มาก` 很)
  - **译文**：有很多好吃的。
* **ของฝาก**（伴手礼 / 纪念品）
  - **词块拆解**：`ของ` (物品) + `ฝาก` (寄托/捎带赠送)
  - **译文**：伴手礼 / 特产礼物。

---

### 41. ให้
**ให้** 原义为“给予”，是句法中最重要的使役、受益及补语标记。
* **拼读与声调构造**：高辅音 **ห** + 特殊短元音 **ใ-** + 调符 **-้** = **降调（第 3 调）**。

#### 核心用法与结构
* **使役动词：让、叫某人做某事（主语 + ให้ + 对象 + 做事）**
  - **例句**：`แม่ให้ผมไปซื้อของ`
    - **拆解**：`แม่` (名词：妈妈) + `ให้` (使役动词：让/叫) + `ผม` (代词：我) + `ไป` (去) + `ซื้อของ` (动词短语：买东西；`ซื้อ` 买 + `ของ` 东西)
    - **译文**：妈妈让我去买东西。
* **介词：替、为、给（受益对象）**
  - **例句**：`ซื้อของขวัญให้เพื่อน`
    - **拆解**：`ซื้อ` (买) + `ของขวัญ` (名词：礼物；`ของ` 物 + `ขวัญ` 吉兆) + `ให้` (介词：给/为) + `เพื่อน` (名词：朋友)
    - **译文**：给朋友买礼物。
* **程度连接词：达到某种状态（使之...）**
  - **例句**：`พูดให้ชัดเจน`
    - **拆解**：`พูด` (动词：说) + `ให้` (程度连接词：使之...) + `ชัดเจน` (形容词/副词：清楚/清晰)
    - **译文**：说清楚一点。

#### 常用高频固定词组
* **ให้ได้**（务必要做到 / 一定要...）
  - **词块拆解**：`ให้` (让/达到) + `ได้` (成功/可以)
  - **例句**：`ต้องทำให้ได้`
  - **拆解**：`ต้อง` (必须) + `ทำ` (做) + `ให้ได้` (一定要做到)
  - **译文**：一定要把它做成功！
* **ยกโทษให้**（原谅某人）
  - **词块拆解**：`ยกโทษ` (免去惩罚/免罪；`ยก` 举起/免 + `โทษ` 惩罚) + `ให้` (给某人)
  - **译文**：原谅（某人）。

---

### 42. ว่า
**ว่า** 是日常转述从句的核心连接词（类似英语 that），亦可作动词“责怪”。
* **拼读与声调构造**：低辅音 **ว** + 长元音 **-า** + 调符 **-่** = **降调（第 3 调）**。

#### 核心用法与结构
* **宾语从句连接词：认为、说、觉得...（动词 + ว่า + 从句）**
  - **例句**：`ฉันคิดว่าเขาเป็นคนดี`
    - **拆解**：`ฉัน` (我) + `คิด` (动词：想/认为) + `ว่า` (连词：引导宾语从句：即...) + `เขา` (他) + `เป็น` (是) + `คนดี` (名词短语：好人；`คน` 人 + `ดี` 好)
    - **译文**：我觉得他是个好人。
  - **例句**：`เขาบอกว่าวันนี้ไม่ว่าง`
    - **拆解**：`เขา` (他) + `บอก` (告诉/说) + `ว่า` (从句连词：说...) + `วันนี้` (今天) + `ไม่ว่าง` (形容词短语：没空；`ไม่` 不 + `ว่าง` 空闲)
    - **译文**：他说今天没空。
* **实义动词：责怪、批评、骂**
  - **例句**：`อย่าว่าเขาเลย`
    - **拆解**：`อย่า` (副词：别/不要) + `ว่า` (动词：责怪/斥责) + `เขา` (代词：他) + `เลย` (语气助词：了/吧)
    - **译文**：别责怪他了吧。

#### 常用高频固定词组
* **คิดว่าไง**（你觉得怎么样？）
  - **词块拆解**：`คิด` (想/觉得) + `ว่า` (即...) + `ไง` (怎样)
  - **译文**：你觉得如何？/ 你怎么看？
* **แปลว่า**（翻译为 / 意思是说...）
  - **词块拆解**：`แปล` (动词：翻译) + `ว่า` (即...)
  - **例句**：`คำนี้แปลว่าอะไร`
  - **拆解**：`คำนี้` (这个单词；`คำ` 词 + `นี้` 这) + `แปลว่า` (翻译为) + `อะไร` (什么)
  - **译文**：这个词是什么意思？

---

### 43. โดน / ถูก
泰语中的被动标记。口语中 `โดน` 极高频，多带“遭受不利/挨...”的感情色彩。
* **拼读与声调构造**：
  - `โดน`：中辅音 **ด** + 长元音 **โ-** + 清尾辅音 **น** = **中平调（第 1 调）**。
  - `ถูก`：高辅音 **ถ** + 长元音 **-ู** + 浊尾辅音 **ก** = **低平调（第 2 调）**。

#### 核心用法与结构
* **表示被动、遭受不利（โดน / ถูก + 动词：被...、挨...）**
  - **例句**：`โดนด่า`
    - **拆解**：`โดน` (被动助词：挨/被) + `ด่า` (动词：骂)
    - **译文**：挨骂 / 被骂了。
  - **例句**：`เขาถูกตำรวจจับ`
    - **拆解**：`เขา` (他) + `ถูก` (被动助词：被) + `ตำรวจ` (名词：警察) + `จับ` (动词：抓捕)
    - **译文**：他被警察抓了。
  - **例句**：`โดนเท`
    - **拆解**：`โดน` (被/挨) + `เท` (动词：倒掉/口语俚语：被放鸽子、被甩)
    - **译文**：被放鸽子了 / 被甩了。
* **`ถูก` 作形容词：便宜 / 正确**
  - **例句**：`ราคาถูกมาก`
    - **拆解**：`ราคา` (名词：价格) + `ถูก` (形容词：便宜) + `มาก` (程度副词：非常)
    - **译文**：价格非常便宜。

#### 常用高频固定词组
* **โดนใจ**（戳中喜好 / 深得我心）
  - **词块拆解**：`โดน` (击中) + `ใจ` (心灵)
  - **例句**：`เพลงนี้โดนใจมาก`
  - **拆解**：`เพลงนี้` (这首歌；`เพลง` 歌 + `นี้` 这) + `โดนใจ` (深得我心) + `มาก` (非常)
  - **译文**：这首歌太戳我了！
* **ถูกต้อง**（正确 / 对的）
  - **词块拆解**：`ถูก` (对) + `ต้อง` (必须/应当)
  - **译文**：完全正确。

---

### 44. 与 / 跟 / กับ
伴随介词：和、跟、与、对...
* **拼读与声调构造**：中辅音 **ก** + 短元音 **-ะ**（变体 **-ั-**）+ 浊尾辅音 **บ** = **低平调（第 2 调）**。

#### 核心用法与结构
* **例句**：`ไปกับใคร`
  - **拆解**：`ไป` (去) + `กับ` (介词：跟/和) + `ใคร` (谁)
  - **译文**：跟谁一起去？
* **例句**：`กินข้าวกับเพื่อน`
  - **拆解**：`กินข้าว` (吃饭) + `กับ` (和) + `เพื่อน` (朋友)
  - **译文**：跟朋友一起吃饭。

---

### 45. 从 / 离 / จาก
起点介词：从、离。
* **拼读与声调构造**：中辅音 **จ** + 长元音 **-า** + 浊尾辅音 **ก** = **低平调（第 2 调）**。

#### 核心用法与结构
* **例句**：`มาจากไหน`
  - **拆解**：`มา` (来) + `จาก` (从) + `ไหน` (哪里)
  - **译文**：你来自哪里？
* **例句**：`จากนี่ถึงนั่น`
  - **拆解**：`จาก` (从) + `นี่` (这里) + `ถึง` (到) + `นั่น` (那里)
  - **译文**：从这里到那里。

---

### 46. 到 / 抵达 / ถึง
终点介词或动词：到、到达、提及。
* **拼读与声调构造**：高辅音 **ถ** + 短元音 **-ึ** + 清尾辅音 **ง** = **升调（第 5 调）**。

#### 核心用法与结构
* **例句**：`ถึงแล้ว`
  - **拆解**：`ถึง` (到达) + `แล้ว` (了)
  - **译文**：已经到了。
* **例句**：`คิดถึงคุณ`
  - **拆解**：`คิดถึง` (动词：想念；`คิด` 想 + `ถึง` 到/及) + `คุณ` (你)
  - **译文**：想念你。

---

### 47. 在...里 / 上 / 下 / 外 (ใน / บน / ใต้ / นอก)
空间方位核心介词。
* **拼读与声调构造**：
  - `ใน`（中平调）：在...里面
  - `บน`（中平调）：在...上面
  - `ใต้`（降调）：在...下面
  - `นอก`（降调）：在...外面

#### 核心用法与结构
* **例句**：`อยู่ในห้อง`
  - **拆解**：`อยู่` (在) + `ใน` (在...里面) + `ห้อง` (房间)
  - **译文**：在房间里。
* **例句**：`วางบนโต๊ะ`
  - **拆解**：`วาง` (动词：放/搁) + `บน` (在...上面) + `โต๊ะ` (桌子)
  - **译文**：放在桌上。

---

### 48. ด้วย
**ด้วย** 是泰语中极高频的多功能词，主要用作副词、介词和语气助词。
* **拼读与声调构造**：中辅音 **ด** + 复合元音 **-ัว**（遇尾辅音变体为 **-ว-**）+ 清尾辅音 **ย** + 调符 **-้**（中辅音 + 二调符）= **降调（第 3 调）**。

#### 核心用法与结构
* **表示“也、同样”（副词，放句末）**
  - **例句**：`ไปด้วย`
    - **拆解**：`ไป` (动词：去) + `ด้วย` (副词：也/一起)
    - **译文**：我也去 / 一起去。
  - **例句**：`ผมชอบอันนี้ด้วย`
    - **拆解**：`ผม` (代词：我) + `ชอบ` (动词：喜欢) + `อันนี้` (代词：这个；`อัน` 个 + `นี้` 这) + `ด้วย` (副词：也)
    - **译文**：我也喜欢这个。
* **表示“用、凭借、通过”（介词，后接工具/方式/原因）**
  - **例句**：`เขียนด้วยดินสอ`
    - **拆解**：`เขียน` (动词：写) + `ด้วย` (介词：用/以) + `ดินสอ` (名词：铅笔)
    - **译文**：用铅笔写。
  - **例句**：`ไปด้วยรถไฟ`
    - **拆解**：`ไป` (动词：去) + `ด้วย` (介词：乘/通过) + `รถไฟ` (名词：火车；`รถ` 车 + `ไฟ` 火)
    - **译文**：坐火车去。
* **表示礼貌请求或呼吁（句末助词，类似“请/帮帮忙/麻烦了”）**
  - **例句**：`ช่วยด้วย`
    - **拆解**：`ช่วย` (动词：帮/救) + `ด้วย` (助词：帮帮忙/拜托)
    - **译文**：救命！/ 帮帮我！
  - **例句**：`ขอโทษด้วยครับ`
    - **拆解**：`ขอโทษ` (动词短语：对不起/抱歉) + `ด้วย` (助词：实在/表达诚意) + `ครับ` (男性敬语)
    - **译文**：实在不好意思 / 非常抱歉。

#### 常用高频固定词组
* **ด้วยกัน**（一起）
  - **词块拆解**：`ด้วย` (伴随) + `กัน` (互相/一同)
  - **例句**：`กินข้าวด้วยกันไหม`
  - **拆解**：`กินข้าว` (吃饭) + `ด้วยกัน` (一起) + `ไหม` (疑问词：吗)
  - **译文**：要一起吃饭吗？
* **ยินดีด้วย**（恭喜 / 祝贺）
  - **词块拆解**：`ยินดี` (高兴/乐意) + `ด้วย` (也/一同为您高兴)
  - **例句**：`ยินดีด้วยนะ`
  - **拆解**：`ยินดีด้วย` (恭喜) + `นะ` (语气词：哦/呀)
  - **译文**：恭喜你呀！
* **ด้วยความยินดี**（非常乐意 / 不客气）
  - **词块拆解**：`ด้วย` (凭借/带着) + `ความยินดี` (名词：乐意/愉快；前缀 `ความ-` + `ยินดี`)
  - **译文**：非常乐意 / 不用客气（回答对方感谢）。

---

### 49. ตาม
介词或动词：顺着、按照、跟着。
* **拼读与声调构造**：中辅音 **ต** + 长元音 **-า** + 清尾辅音 **ม** = **中平调（第 1 调）**。

#### 核心用法与结构
* **例句**：`เดินตามผมมา`
  - **拆解**：`เดิน` (走) + `ตาม` (跟着) + `ผม` (我) + `มา` (来)
  - **译文**：跟着我走过来。
* **例句**：`ตามใจคุณ`
  - **拆解**：`ตามใจ` (动词短语：随心/随你便；`ตาม` 顺从 + `ใจ` 心) + `คุณ` (你)
  - **译文**：随你的便 / 听你的。

---

### 50. เกี่ยวกับ
介词短语：关于、有关...
* **拼读与声调构造**：`เกี่ยว`（低平调）+ `กับ`（低平调）。

#### 核心用法与结构
* **例句**：`เกี่ยวกับเรื่องอะไร`
  - **拆解**：`เกี่ยวกับ` (关于) + `เรื่อง` (事情/话题) + `อะไร` (什么)
  - **译文**：是关于什么事情的？

---

### 51. อัน
通用量词（个/件）、指示代词（这个 `อันนี้`）或定语关系词（所...的）。
* **拼读与声调构造**：中辅音 **อ** + 短元音 **-ะ**（变体 **-ั-**）+ 清尾辅音 **น** = **中平调（第 1 调）**。

#### 核心用法与结构
* **例句**：`เอาอันนี้`
  - **拆解**：`เอา` (动词：要) + `อัน` (量词：个) + `นี้` (指示：这)
  - **译文**：要这个。
* **例句**：`มีสองอัน`
  - **拆解**：`มี` (有) + `สอง` (数词：两) + `อัน` (量词：个)
  - **译文**：有两个。

---

# 第 5 层：口语连词与常用关联句式

说话时把前后两句话自然串联起来的逻辑连接词。

---

### 52. และ / กับ
并列连词：和、并且、与（口语连接人与物极常用 `กับ`）。
* **拼读与声调构造**：
  - `และ`（高平调）：短元音 **แ-ะ** + 死音节。
  - `กับ`（低平调）。

#### 核心用法与结构
* **例句**：`ผมและเพื่อน`
  - **拆解**：`ผม` (我) + `และ` (和/并且) + `เพื่อน` (朋友)
  - **译文**：我和朋友。

---

### 53. หรือ
选择连词：或者、还是。
* **拼读与声调构造**：高辅音 **ห** + 长元音 **-ื** + 前引 **อ** = **升调（第 5 调）**。

#### 核心用法与结构
* **例句**：`กินข้าวหรือก๋วยเตี๋ยว`
  - **拆解**：`กินข้าว` (吃米饭) + `หรือ` (或者/还是) + `ก๋วยเตี๋ยว` (粿条/粉面)
  - **译文**：吃米饭还是吃粿条？

---

### 54. แต่ / แต่ว่า
转折连词：但是、不过。
* **拼读与声调构造**：`แต่`（低平调）+ `ว่า`（降调）。

#### 核心用法与结构
* **例句**：`อยากไปแต่ไม่มีเวลา`
  - **拆解**：`อยากไป` (想去) + `แต่` (但是) + `ไม่มีเวลา` (没有时间)
  - **译文**：想去但是没时间。

---

### 55. 因为...所以就... (เพราะ / เพราะว่า...ก็เลย...)
口语最地道的因果关联句式。
* **拼读与声调构造**：`เพราะ`（高平调）+ `ก็เลย`（中平调组合）。

#### 核心用法与结构
* **例句**：`เพราะฝนตก ก็เลยมาสาย`
  - **拆解**：`เพราะ` (因为) + `ฝนตก` (下雨) + `ก็เลย` (所以就/于是) + `มาสาย` (迟到；`มา` 来 + `สาย` 晚)
  - **译文**：因为下雨，所以就迟到了。

---

### 56. แล้วก็
口语承接词：然后、还有。
* **拼读与声调构造**：`แล้ว` (高平调) + `ก็` (降调)。

#### 核心用法与结构
* **例句**：`เอาต้มยำกุ้ง แล้วก็น้ำเปล่า`
  - **拆解**：`เอา` (要) + `ต้มยำกุ้ง` (冬阴功虾汤) + `แล้วก็` (然后还有) + `น้ำเปล่า` (纯净水)
  - **译文**：要一份冬阴功虾汤，然后再来一瓶纯水。

---

### 57. 一...就... (พอ...ก็...)
时间顺承句式：刚...就... / 一...就...
* **拼读与声调构造**：`พอ` (中平调) + `ก็` (降调)。

#### 核心用法与结构
* **例句**：`พอกินเสร็จก็กลับบ้าน`
  - **拆解**：`พอ` (一/刚...) + `กินเสร็จ` (吃完) + `ก็` (就) + `กลับบ้าน` (回家)
  - **译文**：刚一吃完就回家了。

---

### 58. 如果...就... (ถ้า...ก็...)
条件假设句式：如果...就...
* **拼读与声调构造**：`ถ้า` (降调) + `ก็` (降调)。

#### 核心用法与结构
* **例句**：`ถ้าชอบก็ซื้อเลย`
  - **拆解**：`ถ้า` (如果) + `ชอบ` (喜欢) + `ก็` (就) + `ซื้อ` (买) + `เลย` (直接/立刻)
  - **译文**：喜欢的话就直接买吧！

---

### 59. ไม่งั้น / ไม่อย่างนั้น
反向假设连词：不然的话、否则（口语极常说 `ไม่งั้น`）。
* **拼读与声调构造**：`ไม่งั้น`（降调组合）。

#### 核心用法与结构
* **例句**：`รีบไป ไม่งั้นสายนะ`
  - **拆解**：`รีบไป` (快点去) + `ไม่งั้น` (不然的话) + `สาย` (迟到) + `นะ` (语气词)
  - **译文**：快点去，不然要迟到了哦。

# 第 6 层：口语程度、范围与副词修饰

用来表达程度强弱、数量范围与发生频率。

### 60. มาก
基本程度副词：很、非常、很多。
* **拼读与声调构造**：低辅音 **ม** + 长元音 **-า** + 浊尾辅音 **ก** = **降调（第 3 调）**。

#### 核心用法与结构
* **例句**：`อร่อยมาก`
  - **拆解**：`อร่อย` (好吃) + `มาก` (非常/很)
  - **译文**：非常好吃。

---

### 61. โคตร
年轻人口语俚语程度词：极其、巨、超级、贼...（情绪强烈）。
* **拼读与声调构造**：中辅音 **ค**（低辅音）+ 长元音 **โ-** + 浊尾辅音 **ตร** = **降调（第 3 调）**。

#### 核心用法与结构
* **例句**：`โคตรแพง`
  - **拆解**：`โคตร` (巨/极其) + `แพง` (贵)
  - **译文**：巨贵！/ 超级贵！
* **例句**：`โคตรดี`
  - **拆解**：`โคตร` (超级) + `ดี` (好)
  - **译文**：绝了！/ 太棒了！

---

### 62. หน่อย / นิดหน่อย
**หน่อย** 本义为微量，日常口语最核心的功能是**软化祈使语气，表达礼貌客气**。
* **拼读与声调构造**：高辅音 **ห** 前引低辅音 **น**（按高辅音规则）+ 元音 **-อ-** + 清尾辅音 **ย** + 调符 **-่** = **低平调（第 2 调）**。

#### 核心用法与结构
* **用于句末缓和语气、礼貌请求（动词 + หน่อย：...一下）**
  - **例句**：`ขอดูหน่อย`
    - **拆解**：`ขอ` (动词：请求/要) + `ดู` (动词：看) + `หน่อย` (语气助词：一下)
    - **译文**：请让我看一下。
  - **例句**：`ช่วยเปิดประตูหน่อย`
    - **拆解**：`ช่วย` (动词：请/帮忙) + `เปิด` (动词：开) + `ประตู` (名词：门) + `หน่อย` (助词：一下)
    - **译文**：麻烦帮忙开一下门。
* **表示微小数量或轻微程度（常作 `นิดหน่อย`）**
  - **例句**：`เผ็ดนิดหน่อย`
    - **拆解**：`เผ็ด` (形容词：辣) + `นิดหน่อย` (程度副词短语：一点点；`นิด` + `หน่อย`)
    - **译文**：微辣 / 有一点点辣。

#### 常用高频固定词组
* **นิดหน่อย**（一点点 / 稍微）
  - **词块拆解**：`นิด` (小量) + `หน่อย` (微量)
  - **例句**：`เหนื่อยนิดหน่อย`
  - **拆解**：`เหนื่อย` (形容词：累) + `นิดหน่อย` (一点点)
  - **译文**：有点累。
* **ช่วยหน่อยได้ไหม**（能帮个忙吗？）
  - **词块拆解**：`ช่วย` (帮) + `หน่อย` (一下) + `ได้ไหม` (可以吗)
  - **译文**：能帮个忙吗？

### 63. เกินไป / ไป
程度过甚副词：太...了、过于...
* **拼读与声调构造**：`เกิน`（中平调）+ `ไป`（中平调）；口语可单用 `ไป` 置于形容词后。

#### 核心用法与结构
* **例句**：`แพงเกินไป / แพงไป`
  - **拆解**：`แพง` (贵) + `เกินไป` (太...了)
  - **译文**：太贵了。

### 64. ค่อนข้าง
副词：比较、相当。
* **拼读与声调构造**：`ค่อน`（降调）+ `ข้าง`（降调）。

#### 核心用法与结构
* **例句**：`ค่อนข้างยาก`
  - **拆解**：`ค่อนข้าง` (比较/相当) + `ยาก` (难)
  - **译文**：比较难。

---

### 65. เกือบ / แทบ
副词：几乎、差点。
* **拼读与声调构造**：
  - `เกือบ`（低平调）：中辅音 **ก** + 复合元音 **เ-ือ** + 浊尾 **บ**。
  - `แทบ`（降调）。

#### 核心用法与结构
* **例句**：`เกือบสายแล้ว`
  - **拆解**：`เกือบ` (差点/几乎) + `สาย` (迟到) + `แล้ว` (了)
  - **译文**：差点就迟到了。

### 66. อีก
**อีก** 表示动作的重复、数量的追加或时间的顺延。
* **拼读与声调构造**：中辅音 **อ** + 长元音 **-ี** + 浊尾辅音 **ก**（中辅音 + 死母）= **低平调（第 2 调）**。

#### 核心用法与结构
* **表示动作重复或继续（副词：又、再）**
  - **例句**：`พูดอีกครั้ง`
    - **拆解**：`พูด` (动词：说) + `อีก` (副词：再/又) + `ครั้ง` (量词：次/遍)
    - **译文**：再说一次。
  - **例句**：`กินอีกไหม`
    - **拆解**：`กิน` (动词：吃) + `อีก` (副词：还/再) + `ไหม` (疑问词：吗)
    - **译文**：还要再吃吗？
* **表示数量追加（又多...、再要...）**
  - **例句**：`ขอน้ำอีกแก้ว`
    - **拆解**：`ขอ` (动词：请求/要) + `น้ำ` (名词：水) + `อีก` (追加：再/另外) + `แก้ว` (量词：杯)
    - **译文**：请再给一杯水。
* **表示时间、距离上的“还有/还要多久”**
  - **例句**：`อีกสองวันจะไป`
    - **拆解**：`อีก` (副词：还有) + `สองวัน` (时间量词：两天；`สอง` 2 + `วัน` 天) + `จะ` (将要) + `ไป` (去)
    - **译文**：还有两天就要去了。

#### 常用高频固定词组
* **อีกแล้ว**（又来了 / 又是这样）
  - **词块拆解**：`อีก` (又) + `แล้ว` (了)
  - **例句**：`มาสายอีกแล้ว`
  - **拆解**：`มาสาย` (迟到；`มา` 来 + `สาย` 迟) + `อีกแล้ว` (又...了)
  - **译文**：又迟到了！
* **อีกนิดนึง**（再稍微多一点点）
  - **词块拆解**：`อีก` (再) + `นิด` (一点) + `นึง` (一个/略微)
  - **例句**：`รออีกนิดนึง`
  - **拆解**：`รอ` (等) + `อีกนิดนึง` (再稍微多一会儿)
  - **译文**：再稍微等一小会儿。

---

### 67. เดียว / เดียวกัน / เดี๋ยว / แป๊บเดียว
**เดียว** 本义为“单一”，与其变体构成了极高频的数量与时间系统。
* **拼读与声调构造**：
  - `เดียว`：中辅音 **ด** + 复合元音 **เ-ีย** + 清尾辅音 **ว** = **中平调（第 1 调）**。
  - `เดี๋ยว`：中辅音 **ด** + 复合短元音 **เ-ียะ**（遇尾辅音变形）+ 清尾 **ว** + 调符 **-๋** = **升调（第 5 调）**。

#### 核心用法与结构
* **表示数量唯一、单独（量词/名词 + เดียว：仅仅一个、独自）**
  - **例句**：`มาคนเดียว`
    - **拆解**：`มา` (动词：来) + `คน` (量词/名词：人) + `เดียว` (形容词：单/独)
    - **译文**：一个人来 / 独自前来。
  - **例句**：`รอนิดเดียว`
    - **拆解**：`รอ` (动词：等) + `นิด` (数量词：少许) + `เดียว` (强调副词：仅仅/只有)
    - **译文**：等一小会儿即可。
* **`เดียวกัน` 表示“相同、同一”（名词/量词 + เดียวกัน）**
  - **例句**：`อยู่บ้านหลังเดียวกัน`
    - **拆解**：`อยู่` (住/在) + `บ้าน` (房子) + `หลัง` (量词：栋/座) + `เดียวกัน` (形容词短语：同一个；`เดียว` 一 + `กัน` 互/同)
    - **译文**：住在同一栋房子里。
* **`เดี๋ยว` 表示时间短暂、马上、片刻（时间副词）**
  - **例句**：`เดี๋ยวเจอกัน`
    - **拆解**：`เดี๋ยว` (时间副词：待会儿/马上) + `เจอ` (动词：见) + `กัน` (互相代词：彼此)
    - **译文**：待会儿见。

#### 常用高频固定词组
* **แป๊บเดียว**（转眼间 / 一眨眼功夫）
  - **词块拆解**：`แป๊บ` (片刻) + `เดียว` (仅仅一个)
  - **例句**：`รอแป๊บเดียว`
  - **拆解**：`รอ` (等) + `แป๊บเดียว` (一小会儿)
  - **译文**：稍等一下下。
* **เดี๋ยวนี้**（现在马上 / 立刻）
  - **词块拆解**：`เดี๋ยว` (片刻) + `นี้` (这)
  - **例句**：`ไปเดี๋ยวนี้เลย`
  - **拆解**：`ไป` (去) + `เดี๋ยวนี้` (立刻/马上) + `เลย` (立刻/直接)
  - **译文**：现在马上就去！

---

### 68. เอง
**เอง** 强调主体独立性（亲自），或作为限定语气词表达“而已”。
* **拼读与声调构造**：中辅音 **อ** + 长元音 **เ-** + 清尾辅音 **ง** = **中平调（第 1 调）**。

#### 核心用法与结构
* **反身代词：自己、亲力亲为（动词/代词 + เอง）**
  - **例句**：`ทำเอง`
    - **拆解**：`ทำ` (动词：做) + `เอง` (副词：自己/亲自)
    - **译文**：自己做 / 亲自动手。
  - **例句**：`ฉันไปเองได้`
    - **拆解**：`ฉัน` (代词：我) + `ไป` (去) + `เอง` (自己) + `ได้` (可以)
    - **译文**：我自己能去。
* **句末语气限定词：才...而已、仅仅（数量/时间后）**
  - **例句**：`ราคาแค่นี้เอง`
    - **拆解**：`ราคา` (名词：价格) + `แค่นี้` (代词短语：就这么点；`แค่` 仅 + `นี้` 这) + `เอง` (语气词：而已)
    - **译文**：价格才这么点儿而已。
  - **例句**：`เพิ่งสิบโมงเอง`
    - **拆解**：`เพิ่ง` (副词：才/刚) + `สิบโมง` (时间名词：上午十点；`สิบ` 10 + `โมง` 点钟) + `เอง` (语气词：而已)
    - **译文**：才上午十点而已。

#### 常用高频固定词组
* **ตัวเอง**（你自己 / 亲爱的）
  - **词块拆解**：`ตัว` (身体/身躯) + `เอง` (自身)
  - **例句**：`ดูแลตัวเองด้วยนะ`
  - **拆解**：`ดูแล` (动词：照顾) + `ตัวเอง` (你自己) + `ด้วย` (助词：顺便/也要) + `นะ` (语气词)
  - **译文**：也要好好照顾自己哦。
* **คนกันเอง**（自己人 / 熟人）
  - **词块拆解**：`คน` (人) + `กัน` (互相) + `เอง` (自己)
  - **译文**：自己人（例：不用客气，大家都是自己人）。

### 69. กัน
**กัน** 表示动作的双向互动、共同协同或阻挡防备。
* **拼读与声调构造**：中辅音 **ก** + 短元音 **-ะ**（变体为 **-ั-**）+ 清尾辅音 **น** = **中平调（第 1 调）**。

#### 核心用法与结构
* **表示相互、彼此（动词 + กัน：互相...）**
  - **例句**：`คุยกัน`
    - **拆解**：`คุย` (动词：聊/谈) + `กัน` (互相副词：彼此)
    - **译文**：互相聊天 / 交谈。
  - **例句**：`เจอกันใหม่`
    - **拆解**：`เจอ` (动词：见/遇) + `กัน` (互相) + `ใหม่` (副词：重新/再)
    - **译文**：下次再见。
* **表示协同、一起做（动词 + กัน：大家一块儿...）**
  - **例句**：`ช่วยกันทำงาน`
    - **拆解**：`ช่วย` (动词：协助) + `กัน` (副词：共同/一起) + `ทำงาน` (动词短语：工作)
    - **译文**：齐心协力一起工作。
* **实义动词：防范、阻隔（防...）**
  - **例句**：`ครีมกันแดด`
    - **拆解**：`ครีม` (名词：霜/乳霜) + `กัน` (动词：防/抗) + `แดด` (名词：烈日/阳光)
    - **译文**：防晒霜。

#### 常用高频固定词组
* **เหมือนกัน**（一样 / 同样）
  - **词块拆解**：`เหมือน` (像/相似) + `กัน` (互相)
  - **例句**：`คิดเหมือนกัน`
  - **拆解**：`คิด` (想/觉得) + `เหมือนกัน` (同样/一样)
  - **译文**：想法一致 / 我也这么想。
* **ไปด้วยกัน**（一起去）
  - **词块拆解**：`ไป` (去) + `ด้วยกัน` (一起)
  - **译文**：一起去。

### 70. ค่อย
副词：慢慢来、稍后再... / 否定中表程度不深（不怎么）。
* **拼读与声调构造**：低辅音 **ค** + 元音 **-อ-** + 清尾辅音 **ย** + 调符 **-่** = **降调（第 3 调）**。

#### 核心用法与结构
* **例句**：`พรุ่งนี้ค่อยคุยกัน`
  - **拆解**：`พรุ่งนี้` (时间词：明天) + `ค่อย` (副词：稍后/再) + `คุย` (动词：聊) + `กัน` (副词：互相)
  - **译文**：明天再聊吧。
* **例句**：`ค่อยๆ เดิน`
  - **拆解**：`ค่อยๆ` (叠词副词：慢慢地) + `เดิน` (动词：走)
  - **译文**：慢慢走 / 小心脚下。

### 71. เลย
**เลย** 是表达极致语气、直接承接与物理越界的万能口语词。
* **拼读与声调构造**：低辅音 **ล** + 元音 **เ-อ**（遇尾辅音 **ย** 变形为 **เลย**）+ 清尾辅音 **ย** + 无调符 = **中平调（第 1 调）**。

#### 核心用法与结构
* **否定句末，表示“完全不、根本不”（ไม่...เลย）**
  - **例句**：`ไม่ชอบเลย`
    - **拆解**：`ไม่` (否定词：不) + `ชอบ` (动词：喜欢) + `เลย` (程度助词：根本/完全)
    - **译文**：一点也不喜欢 / 根本不喜欢。
  - **例句**：`ไม่หิวเลย`
    - **拆解**：`ไม่` (不) + `หิว` (形容词：饿) + `เลย` (完全)
    - **译文**：一点都不饿。
* **表示顺理成章、直接立刻行动（就...吧、直接去...）**
  - **例句**：`ถ้าชอบก็ซื้อเลย`
    - **拆解**：`ถ้า` (连词：如果) + `ชอบ` (喜欢) + `ก็` (副词：就) + `ซื้อ` (动词：买) + `เลย` (副词：直接/立刻)
    - **译文**：喜欢的话就直接买吧！
  - **例句**：`ไปเลย`
    - **拆解**：`ไป` (动词：去) + `เลย` (副词：立刻/马上)
    - **译文**：马上出发 / 直接去！
* **表示空间/时间越界、走过头（超过、越过）**
  - **例句**：`เดินเลยไปแล้ว`
    - **拆解**：`เดิน` (动词：走) + `เลย` (动词/介词：越过/走过头) + `ไป` (方向：去) + `แล้ว` (助词：已经)
    - **译文**：已经走过头了。

#### 常用高频固定词组
* **ดีเลย**（太棒了 / 正好！）
  - **词块拆解**：`ดี` (好) + `เลย` (极度/正是)
  - **译文**：太棒了 / 正好合适！（赞同对方提议）。
* **ใช่เลย**（一点没错 / 就是这样！）
  - **词块拆解**：`ใช่` (对/是) + `เลย` (正是)
  - **译文**：一点没错！/ 完全赞同。

---

### 72. บ่อยๆ / เสมอ
频率副词：经常、常常 / 总是。
* **拼读与声调构造**：`บ่อย`（低平调）；`เสมอ`（升调）。

#### 核心用法与结构
* **例句**：`มาที่นี่บ่อยๆ ไหม`
  - **拆解**：`มา` (来) + `ที่นี่` (这里) + `บ่อยๆ` (经常/常常) + `ไหม` (吗)
  - **译文**：你经常来这里吗？

---

# 第 7 层：动词趋向与口语结果补语

泰语中极为生动的空间动向与结果表达，放在动词后面充当补语。

---

### 73. ขึ้น
**ขึ้น** 作方向补语，表示“上升、增加、变好”。
* **拼读与声调构造**：高辅音 **ข** + 短元音 **-ึ** + 清尾辅音 **น** + 调符 **-้** = **降调（第 3 调）**。

#### 核心用法与结构
* **形容词后，表示程度增加、状态好转（变...、更...）**
  - **例句**：`เก่งขึ้นมาก`
    - **拆解**：`เก่ง` (形容词：厉害/棒) + `ขึ้น` (程度补语：变得更.../上升) + `มาก` (程度副词：非常)
    - **译文**：变得厉害多了 / 进步非常大。
  - **例句**：`อากาศร้อนขึ้น`
    - **拆解**：`อากาศ` (名词：天气/气候) + `ร้อน` (形容词：热) + `ขึ้น` (状态补语：变得更...)
    - **译文**：天气变热了。
* **动词后，表示物理向上或登车**
  - **例句**：`ยืนขึ้น`
    - **拆解**：`ยืน` (动词：站) + `ขึ้น` (趋向补语：起来/向上)
    - **译文**：站起来。
  - **例句**：`ขึ้นรถ`
    - **拆解**：`ขึ้น` (动词：上/登) + `รถ` (名词：车)
    - **译文**：上车。

#### 常用高频固定词组
* **ดีขึ้น**（变好 / 好转）
  - **词块拆解**：`ดี` (好) + `ขึ้น` (上升)
  - **例句**：`อาการดีขึ้นแล้ว`
  - **拆解**：`อาการ` (名词：病情/症状) + `ดีขึ้น` (好转) + `แล้ว` (了)
  - **译文**：病情已经好转了。
* **เกิดขึ้น**（发生）
  - **词块拆解**：`เกิด` (动词：生出/产生) + `ขึ้น` (起来)
  - **例句**：`เกิดอะไรขึ้น`
  - **拆解**：`เกิด` (发生) + `อะไร` (什么) + `ขึ้น` (补语：起来)
  - **译文**：发生什么事了？

---

### 74. ลง
**ลง** 作方向补语，表示“下降、减少、变弱、记录”。
* **拼读与声调构造**：低辅音 **ล** + 隐含短元音 **โ-ะ** + 清尾辅音 **ง** = **中平调（第 1 调）**。

#### 核心用法与结构
* **形容词后，表示程度减弱、状态平息（变少、变弱）**
  - **例句**：`ผอมลง`
    - **拆解**：`ผอม` (形容词：瘦) + `ลง` (状态补语：变得更.../下降)
    - **译文**：瘦下来了。
  - **例句**：`ฝนเบาลงแล้ว`
    - **拆解**：`ฝน` (名词：雨) + `เบา` (形容词：轻/微弱) + `ลง` (状态补语：减弱) + `แล้ว` (助词：已经)
    - **译文**：雨势已经变小了。
* **动词后，表示物理向下或抄写记录**
  - **例句**：`นั่งลง`
    - **拆解**：`นั่ง` (动词：坐) + `ลง` (趋向补语：下/向下)
    - **译文**：坐下。
  - **例句**：`จดลงในสมุด`
    - **拆解**：`จด` (动词：记/抄写) + `ลง` (动作补语：下/落) + `ใน` (介词：在...里) + `สมุด` (名词：笔记本)
    - **译文**：记录在笔记本上。

#### 常用高频固定词组
* **ลดลง**（降低 / 减少）
  - **词块拆解**：`ลด` (动词：减少/降低) + `ลง` (向下)
  - **例句**：`ราคาลดลงแล้ว`
  - **拆解**：`ราคา` (价格) + `ลดลง` (降低了) + `แล้ว` (了)
  - **译文**：价格降下来了。
* **ลงรถ**（下车）
  - **词块拆解**：`ลง` (下) + `รถ` (车)
  - **译文**：下车。

---

### 75. เข้า
趋向动词或补语：进入、穿上、融入。
* **拼读与声调构造**：高辅音 **ข** + 特殊短元音 **เ-า** + 调符 **-้** = **降调（第 3 调）**。

#### 核心用法与结构
* **例句**：`เข้ามาสิ`
  - **拆解**：`เข้ามา` (进来；`เข้า` 进 + `มา` 来) + `สิ` (语气词：呀/吧)
  - **译文**：快请进呀！

---

### 76. ออก
**ออก** 作补语，表示“向外脱离”或“认出、想出、看透”。
* **拼读与声调构造**：中辅音 **อ** + 元音 **-อ-** + 浊尾辅音 **ก** = **低平调（第 2 调）**。

#### 核心用法与结构
* **认知动词后，表示辨识与想通（想出来、看出来）**
  - **例句**：`คิดออกแล้ว`
    - **拆解**：`คิด` (动词：想) + `ออก` (结果补语：出/想通) + `แล้ว` (助词：已经)
    - **译文**：想出来了 / 想通了。
  - **例句**：`ดูไม่ออก`
    - **拆解**：`ดู` (动词：看) + `ไม่ออก` (否定结果补语：看不出/辨认不出；`ไม่` + `ออก`)
    - **译文**：看不出来 / 辨认不出来。
* **动词后，表示物理向外脱离**
  - **例句**：`เดินออกไป`
    - **拆解**：`เดิน` (动词：走) + `ออก` (趋向补语：出/向外) + `ไป` (方向动词：去)
    - **译文**：走出去。

#### 常用高频固定词组
* **คิดไม่ออก**（想不出来 / 没辙）
  - **词块拆解**：`คิด` (想) + `ไม่` (不) + `ออก` (出)
  - **例句**：`ตอนนี้คิดไม่ออกเลย`
  - **拆解**：`ตอนนี้` (现在) + `คิดไม่ออก` (想不出来) + `เลย` (完全/根本)
  - **译文**：现在完全想不出来了。
* **นึกออก**（想起来了 / 回忆起来了）
  - **词块拆解**：`นึก` (忆/思索) + `ออก` (出)
  - **例句**：`นึกออกแล้ว`
  - **拆解**：`นึกออก` (想起来了) + `แล้ว` (了)
  - **译文**：我想起来了！

---

### 77. ไป / มา
基本方向趋向补语（去：远离说话人 / 来：接近说话人）。
* **拼读与声调构造**：`ไป`（中平调）；`มา`（中平调）。

#### 核心用法与结构
* **例句**：`เอามาให้ดูหน่อย`
  - **拆解**：`เอามา` (拿过来；`เอา` 拿 + `มา` 来) + `ให้` (给/让) + `ดู` (看) + `หน่อย` (一下)
  - **译文**：拿过来给我看一下。
* **例句**：`เดินกลับไป`
  - **拆解**：`เดิน` (走) + `กลับไป` (走回去；`กลับ` 回 + `ไป` 去)
  - **译文**：走回去。

---

### 78. ทัน
口语结果补语：赶得上、来得及。
* **拼读与声调构造**：低辅音 **ท** + 短元音 **-ะ**（变体 **-ั-**）+ 清尾辅音 **น** = **中平调（第 1 调）**。

#### 核心用法与结构
* **例句**：`ไปไม่ทัน`
  - **拆解**：`ไป` (去) + `ไม่ทัน` (来不及/赶不上；`ไม่` + `ทัน`)
  - **译文**：赶不上了 / 来不及去了。
* **例句**：`ทันเวลาพอดี`
  - **拆解**：`ทันเวลา` (赶上时间；`ทัน` + `เวลา` 时间) + `พอดี` (副词：正好/恰好)
  - **译文**：正好赶上时间。

---

### 79. ติด
口语状态结果：卡住、接通、沉迷、堵车。
* **拼读与声调构造**：中辅音 **ต** + 短元音 **-ิ** + 浊尾辅音 **ด** = **低平调（第 2 调）**。

#### 核心用法与结构
* **例句**：`รถติดมาก`
  - **拆解**：`รถ` (车) + `ติด` (卡住/堵塞) + `มาก` (非常)
  - **译文**：堵车非常严重。
* **例句**：`โทรไม่ติด`
  - **拆解**：`โทร` (打电话) + `ไม่ติด` (打不通/未接通)
  - **译文**：电话打不通。

---

# 第 8 层：泰国人口语的灵魂——句末语气词

掌握这组语气词，你的泰语立刻从“机械翻译腔”变成“地道泰国本地腔”！

---

### 80. นะ
* **功能与情绪**：提醒、叮嘱、撒娇、拉近距离（“哦”、“哈”、“呀”）。
* **例句**：`ไปก่อนนะ`
  - **拆解**：`ไป` (走) + `ก่อน` (先) + `นะ` (语气词：哦/呀)
  - **译文**：我先走啦哦！
* **例句**：`ช่วยหน่อยนะ`
  - **拆解**：`ช่วย` (帮) + `หน่อย` (一下) + `นะ` (语气词：嘛)
  - **译文**：帮个忙嘛！

---

### 81. สิ / ดิ
* **功能与情绪**：催促、确认事实、强调理所当然（“啊”、“呀”、“呗”）。
* **例句**：`กินสิ`
  - **拆解**：`กิน` (吃) + `สิ` (语气词：呀/快吃吧)
  - **译文**：快吃呀！
* **例句**：`ใช่ดิ`
  - **拆解**：`ใช่` (对/是) + `ดิ` (口语语气词：那可不是嘛/就是啊)
  - **译文**：那当然啦！/ 就是啊！

---

### 82. หรอก
* **功能与情绪**：否定句专属：反驳、安慰、消除顾虑（“才没有...呢”、“才不...”）。
* **例句**：`ไม่แพงหรอก`
  - **拆解**：`ไม่แพง` (不贵) + `หรอก` (语气词：才不...呢)
  - **译文**：才不贵呢 / 不贵的啦！
* **例句**：`ไม่เป็นไรหรอก`
  - **拆解**：`ไม่เป็นไร` (没关系) + `หรอก` (语气词：没事的啦)
  - **译文**：没事的啦！

---

### 83. มั้ง
* **功能与情绪**：不确定、猜测、大概推断（“吧”、“大概吧”）。
* **例句**：`เขาไม่มามั้ง`
  - **拆解**：`เขา` (他) + `ไม่มา` (不来) + `มั้ง` (语气词：大概...吧)
  - **译文**：他大概不来了吧。

---

### 84. เถอะ / เหอะ
* **功能与情绪**：劝说、妥协、建议（干脆做某事，“...吧”、“得了吧”）。
* **例句**：`ไปเถอะ`
  - **拆解**：`ไป` (走/去) + `เถอะ` (语气词：...吧)
  - **译文**：走吧走吧！
* **例句**：`พอเหอะ`
  - **拆解**：`พอ` (够了/停) + `เหอะ` (语气词：算了吧/得了吧)
  - **译文**：算了吧！/ 得了吧！

---

### 85. เนี่ย
* **功能与情绪**：强调当前焦点、略带抱怨或强调（“这个...呀”、“到底...”）。
* **例句**：`อะไรเนี่ย`
  - **拆解**：`อะไร` (什么) + `เนี่ย` (语气词：搞什么呀/这是啥呀)
  - **译文**：搞什么呀！/ 这是什么鬼呀！
* **例句**：`ทำไมร้อนขนาดนี้เนี่ย`
  - **拆解**：`ทำไม` (为什么) + `ร้อน` (热) + `ขนาดนี้` (这么/到这个程度) + `เนี่ย` (语气词)
  - **译文**：怎么会热成这个样子呀！

---

### 86. ไง / ไงล่ะ
* **功能与情绪**：提醒对方早已知道的事实、反问（“就是...嘛”、“看吧”）。
* **例句**：`บอกแล้วไง`
  - **拆解**：`บอก` (说) + `แล้ว` (已经) + `ไง` (语气词：早就...了嘛)
  - **译文**：我早就跟你说过了嘛！

---

### 87. อ่ะ
* **功能与情绪**：引起注意、停顿、撒娇略带委屈（“嘛”、“啊”）。
* **例句**：`ทำไมอ่ะ`
  - **拆解**：`ทำไม` (为什么) + `อ่ะ` (语气词：干嘛啦/为什么呀)
  - **译文**：干嘛啦？/ 为什么呀？

---

### 88. เหรอ / หรอ
* **功能与情绪**：疑问反问（听到新信息感到意外，“是吗？”、“真的吗？”）。
* **例句**：`จริงเหรอ`
  - **拆解**：`จริง` (真的) + `เหรอ` (疑问语气词：真的吗？)
  - **译文**：真的吗？！

---

### 89. จ้า / จ้ะ
* **功能与情绪**：亲切答应、礼貌回应（长辈对晚辈、店家对熟客、女性对朋友，“好嘞”、“收到啦”）。
* **例句**：`ขอบคุณจ้า`
  - **拆解**：`ขอบคุณ` (谢谢) + `จ้า` (亲切语气词)
  - **译文**：谢谢啦！

---

| **เอง** | 中平调 (中辅音 + 清尾) | 亲力亲为 (自己做)、语气限定 (而已) | `ทำเอง` (自己做), `แค่นี้เอง` (仅此而已), `ตัวเอง` (亲爱的) |
| **กัน** | 中平调 (中辅音 + 清尾) | 互相动作、共同行为、防护隔离 | `คุยกัน` (聊天), `ช่วยกัน` (齐心合力), `เหมือนกัน` (同样) |
| **ให้** | 降调 (高辅音 + 二调符) | 使役 (让)、受益介词 (替/给)、程度副词 | `ให้ผมดู` (让我看), `ซื้อให้` (买给...), `ให้ได้` (务必做到) |
| **ที่** | 降调 (低辅音 + 一调符) | 定语从句引词 (...的)、介词 (在)、序数词 (第) | `ที่นี่` (这里), `คนที่รัก` (所爱之人), `ครั้งที่หนึ่ง` (第一次) |
| **ว่า** | 降调 (低辅音 + 一调符) | 宾语从句引词 (认为/说...)、责怪 | `คิดว่า` (觉得...), `บอกว่า` (说道...), `แปลว่า` (意思是) |
| **ของ** | 升调 (高辅音 + 清尾) | 所属助词 (...的)、名词 (东西物品) | `ของฉัน` (我的), `ซื้อของ` (买东西), `ของกิน` (美食) |

| **ขึ้น** | 降调 (高辅音 + 二调符) | 趋向上升、程度增加、状态变好 | `ดีขึ้น` (变好), `เก่งขึ้น` (变厉害), `ยืนขึ้น` (站起来) |
| **ลง** | 中平调 (低辅音 + 清尾) | 趋向下降、程度减弱、状态平息、记录 | `ผอมลง` (瘦了), `ลดลง` (减少), `นั่งลง` (坐下), `จดลง` (记下) |
| **ออก** | 低平调 (中辅音 + 浊尾) | 趋向外部、认知识别 (想通/看出) | `คิดออก` (想出来了), `ดูไม่ออก` (看不出), `ออกไป` (出去) |
| **ซะ / เสีย** | 高平调 (低辅音 + 死音节) | 动作彻底完成、口语催促、惋惜遗憾 | `กินซะ` (快吃吧), `สายซะแล้ว` (太迟了), `เสียใจ` (难过) |

### 2. 日常口语核心万能句型公式表

| 口语核心句式 | 含义与使用场景 | 典型例句与拆解 |
| :--- | :--- | :--- |
| **`动词` + อะไรดี** | 吃/做/买什么好呢？（纠结时征求意见） | `เย็นนี้กินอะไรดี` (今晚吃什么好呢？；`เย็นนี้` 今晚 + `กิน` 吃 + `อะไรดี` 什么好) |
| **...แล้วหรือยัง / ...แล้วยัง** | ...了没有？（询问动作完成情况） | `ถึงแล้วยัง` (到了没有？；`ถึง` 到达 + `แล้วยัง` 了没) |
| **เพราะว่า...ก็เลย...** | 因为...所以就...（最地道口语因果） | `เพราะฝนตก ก็เลยมาสาย` (因为下雨所以迟到了) |
| **ลอง + `动词` + ดูสิ** | 试着做做看呀（建议对方尝试） | `ลองกินดูสิ` (尝一口试试看呀) |
| **`动词` + ไม่ทัน** | 赶不上 / 来不及做某事 | `ตื่นสายไปไม่ทัน` (起晚了赶不上了；`ตื่นสาย` 起床晚了) |
| **`动词` + ไม่ออก** | 想不出 / 认不出 / 说不出口 | `คิดไม่ออก` (想不出来 / 没辙) |
| **บอกแล้วไง** | 我早就跟你说了嘛（熟人口语提示） | `บอกแล้วไงว่าอย่าไป` (我早跟你说了别去嘛) |
| **ขอ...หน่อยครับ/ค่ะ** | 请给我... / 麻烦来一个... (万能点单索取) | `ขอน้ำเปล่าหนึ่งแก้วหน่อยครับ` (麻烦来一杯白开水) |
| **...อยู่ที่ไหน / อยู่ตรงไหน** | ...在哪里？/ 在哪个位置？ (万能问路) | `ห้องน้ำอยู่ที่ไหนครับ` (洗手间在哪里？) |
| **ช่วย...ให้ด้วยได้ไหม** | 能帮忙...吗？ (万能礼貌请求协助) | `ช่วยเปิดประตูให้ด้วยได้ไหมครับ` (能帮忙开下门吗？) |
