# 数字与泰铢货币卡片设计

## 1. 背景

“课程-词根高频词族卡片”当前通过 `WordFamily` 数据模型和统一的翻面/滑动卡片界面展示词根及其高频词族。需要在同一组卡片中新增：

1. 泰语 0–100 数字卡片；
2. 泰铢与萨当货币表达卡片。

目标是让用户既能查阅关键数字，也能通过规则理解 100 以内的组合方式，并掌握整数金额、萨当金额和小数点读法。

## 2. 方案选择

采用复用现有 `WordFamily` 结构的方案，不新增专用卡片类型或独立 UI。

### 选择原因

- 现有 `WordFamilyBrowserView` 会自动加载并浏览 JSON 中的卡片；
- 现有正面/背面布局已经支持标题、说明、条目和单条音频；
- 数字和货币内容中的“关键例子”可以使用 `items`，有规律的内容可以放在 `usageNote`；
- 改动范围集中在内容 JSON、必要的内容测试和项目资源索引，不改变已有卡片交互。

## 3. 数字卡片设计

### 基本信息

- ID：`family-numbers-100`
- 根词显示：`ตัวเลข`
- 中文：`数字 0–100`
- 分类：`basics`
- 说明：用中文说明 0–100 的组合规则和例外。

### 结构化条目

只列出基础数字、关键例外、整十和百位示例，不逐个列出所有有规律的数字：

- 0–10：基础数字；
- 11：说明个位 1 在十位后变为 `เอ็ด`；
- 20：说明特殊形式 `ยี่สิบ`；
- 21：展示 `ยี่สิบ + เอ็ด`；
- 30、40、50、60、70、80、90：各一个整十示例；
- 100：`หนึ่งร้อย`。

### 规则

- 11–19：`สิบ + 个位`；
- 十位后的个位 1 使用 `เอ็ด`，如 `สิบเอ็ด`、`ยี่สิบเอ็ด`；
- 20 特殊读作 `ยี่สิบ`；
- 21–99 通常为“十位数字 + `สิบ` + 个位”；
- 100 为 `หนึ่งร้อย`；
- 22–99 中符合规则的数字不逐个列出，仅通过说明和代表性例子展示规律。

## 4. 货币卡片设计

### 基本信息

- ID：`family-currency-thb`
- 根词显示：`บาท`
- 中文：`泰铢与萨当`
- 分类：`basics`
- 说明：区分日常金额读法和按小数点读数字的方式。

### 结构化条目

包含以下代表性金额：

- 1 泰铢：`หนึ่งบาท`；
- 21 泰铢：`ยี่สิบเอ็ดบาท`；
- 50 泰铢：`ห้าสิบบาท`；
- 100 泰铢：`หนึ่งร้อยบาท`；
- 0.50 泰铢：`ห้าสิบสตางค์`；
- 21.50 泰铢：`ยี่สิบเอ็ดบาทห้าสิบสตางค์`；
- 3.25 泰铢：`สามบาทยี่สิบห้าสตางค์`；
- 21.50 按小数点读：`ยี่สิบเอ็ดจุดห้าศูนย์`。

### 规则

- 整数金额：数字 + `บาท`；
- 小数金额的日常货币读法：整数 + `บาท` + 萨当数 + `สตางค์`；
- 只有小数部分时可直接读萨当，例如 0.50 为 `ห้าสิบสตางค์`；
- 强调数字本身的小数点时使用 `จุด`，小数部分逐位读，例如 21.50 为 `ยี่สิบเอ็ดจุดห้าศูนย์`；
- 通过代表性例子说明组合规则，不穷举金额。

## 5. 音频与资源

- 数字和货币条目沿用现有 `audioID` 约定；
- 没有预生成资源的条目使用现有播放服务的 TTS 回退；
- 不新增例句音频，不改变例句音频管线；
- 所有泰语条目由完整的条目文本播放，不按词块拼接。

## 6. 验收标准

- 词根高频词族卡片列表中新增两张卡片；
- 数字卡片覆盖 0–100，并明确展示 11、20、21、100 等关键形式；
- 数字卡片对有规律数字只给组合规则和代表性例子，不列出 0–100 的全部数字；
- 货币卡片包含 21 泰铢、萨当表达、带小数金额和 `จุด` 小数点读法；
- 两张卡片均能正常翻面、滑动浏览和播放条目音频；
- JSON 可解码，`itemCount` 与条目数量一致，已有词族卡片测试不回归。

## 7. 非目标

- 不新增专用数字/货币 UI；
- 不实现数字或金额的动态转换器；
- 不扩展到 100 以上的完整数字教学；
- 不修改已有音频生成和例句播放逻辑。
