# 泰国招牌无头字对照页设计

**日期：** 2026-08-17
**状态：** 已完成设计，待用户审阅后进入实施

## 背景

已掌握标准泰文字母的学习者，在泰国街头面对店铺招牌、商品广告、促销牌、药店和地铁指示时，常因现代无头字（Loopless Fonts）而无法识读。

现有资料《泰语广告招牌与无头艺术字对照表》已整理标准有头字（Sarabun）、现代无头字（Prompt）、关键字形规律、常见易混字和五类真实场景。本功能将其做成 Thai Life 中一张可反复浏览的离线对照页，帮助用户直接看、直接对照、直接记。

## 目标

1. 在 App 的课程页提供独立入口「泰国招牌无头字对照」。
2. 进入后直接显示一张可滚动的无头字对照页；不出现课程目录、章节页、查询框、学习进度或测试流程。
3. 以真实 Sarabun 标准字和 Prompt 无头字并排渲染，帮助用户建立可靠的字形映射。
4. 覆盖高频街头招牌所需的常见无头字规律、少量易混字提醒和五类真实场景词。
5. 支持点击泰语字或完整场景词播放正确读音；多字场景词必须播放完整词音频。
6. 所有字体与图片可离线使用并具有可审计的 App 分发许可。

## 非目标

- 不创建独立课程目录、章节、关卡、查询输入框、搜索结果、学习进度、完成率或已读状态。
- 不提供测验、选择题、猜词、遮挡、答案按钮、正确/错误反馈、评分、错题、排行榜或连续学习天数。
- 不使用 FSRS 排程、复习队列、收藏练习、学习草稿或卡片评分。
- 不修改现有日常复习、收藏练习、普通课程浏览、词根卡或内容包逻辑。
- 不尝试覆盖所有泰语辅音、所有字体或所有艺术字变体；仅收录真实街头识读价值高的高频内容。
- 不依赖在线 Google Fonts、网络图片或用户设备预装字体。

## 用户入口

在既有「课程」页面的“专项扩展”区域增加一条入口：

```text
泰国招牌无头字对照
看懂广告、店铺、药店与地铁招牌
高频字形 · 易混提醒 · 真实场景
```

点击后直接进入 `LooplessSignageReferenceView`；该页面是一张长页，不再经过目录或章节导航。

## 单页布局

页面标题为「泰国招牌无头字对照」，内容从上到下固定为四个区块。

### 1. 简短说明

```text
泰国现代招牌常把泰文字母的圆圈简化掉。
左边是标准字，右边是街头常见的无头字。
```

说明最多两行，不解释冗长字体史。

### 2. 高频字形对照

以视觉形状分组而不是按完整泰文字母表顺序展示。每条固定显示：

```text
标准字（Sarabun） | 无头字（Prompt） | 最短识别提示
```

收录高频、实用的条目与提示：

| 视觉组 | 代表字 | 识别重点 |
|---|---|---|
| 圆拱 `n` 型 | `ล / ค / ก` 等 | 常像拉丁小写 `n`，结合局部笔画与词判断 |
| `d` 型 | `ด` | 左圆右直，常像小写 `d` |
| `m` 型 | `ต` | 顶部有凹口，常像小写 `m` |
| `h` 型 | `ท` | 左高右低，常像小写 `h` |
| `u` 型 | `น / ม / ย / ป` | 必须观察底部折角、左侧内凹或右腿高度 |
| 带尾巴型 | `ช / ป / ฟ / ส` 等 | 观察右上上扬尾巴、凹口或短撇 |
| 前置元音 | `เ / แ` | 常简化为一条或两条竖线 |

每个字形均可点击播放其标准单字读音。表格应采用卡片/分组行等适合移动端阅读的布局，而不是 HTML 式密集网格；标准字与无头字保持同字号、同基线和明显标签。

### 3. 易混提醒

只保留最有街头识读价值的少量对照，不扩展成练习题：

```text
น  vs  ม
右下内折  vs  左下更平、更扁

ล / ค / ก
都可能像 n；依靠局部笔画和完整词判断

ช / ป / ฟ
观察右侧是否明显上扬、是否保留尾巴
```

每组同屏显示标准字和无头字，说明最多一句。用户只需直接比较记忆，不需要选择或提交答案。

### 4. 真实招牌例子

每个例子在同一页面向下排列，固定包含：

```text
[真实场景图片]
无头招牌词：[泰语词]
标准写法：[泰语词]
中文：[场景含义]
字形提示：[逐字或关键字形说明]
```

必须包含以下场景：

1. 奶茶店：`ชานม`（奶茶）
2. 商场促销：`ลดราคา`（降价／打折）
3. 店门营业牌：`เปิด`（营业），并显示 `ปิด`（关闭）作对照
4. 药店：`ยา`（药／药店）
5. 地铁指示：`ทางออก`（出口），并显示 `ทางเข้า`（入口）作对照

可补充 `จ่าย`（付款）等资料中已有的高频词，但不以填充数量为目标。

场景词、标准写法与图中的重点词均可点击播放完整词音频；不得把单字或词块串接为场景词语音。图片、词义和字形说明默认同时可见，绝不要求用户先猜读或点击显示答案。

## 字体与资源规范

### 离线双字体

- 标准有头字使用 **Sarabun**。
- 现代无头字使用 **Prompt**。
- 两套字体必须作为资源随 App Bundle 分发、在运行时注册，并通过明确字体名称渲染；禁止系统字体回退、在线字体下载或截图式字形替代。
- 实施前必须验证具体字体文件版本及许可允许 iOS App 再分发；将字体来源、版本与许可文件记录在资源归属文档。

### 场景图片

候选图片是资料已使用的五张场景图：奶茶店、促销牌、营业门牌、药店、地铁出口。导入 App 前逐张审计：

1. 原始来源和作者／生成方式；
2. iOS App 离线再分发许可；
3. 是否要求署名及署名原文；
4. 可识别人物、商标和其他受限素材的风险。

许可无法证明的图片不得进入 App Bundle，必须以有明确可商用许可的原创、授权或合规生成替代图替换。

### 独立资源模型

无头字对照页使用独立 JSON，不能污染普通 `ContentItem` 内容包：

```text
ThaiLife/Resources/Content/loopless_signage_reference.json
```

建议模型：

```text
LooplessGlyphEntry
- id
- standardThai
- looplessThai
- thaiName
- pronunciationText
- visualHintZhHans
- exampleWordIDs

LooplessConfusionGroup
- id
- glyphEntryIDs
- comparisonHintZhHans

LooplessScene
- id
- titleZhHans
- imageAssetID
- thaiWord
- standardThaiWord
- meaningZhHans
- audioID
- glyphExplanationZhHans
- sourceAttribution
```

资源目录：

```text
ThaiLife/Resources/Fonts/Sarabun-*.ttf
ThaiLife/Resources/Fonts/Prompt-*.ttf
ThaiLife/Resources/LooplessSignage/[scene-image-files]
ThaiLife/Resources/Content/loopless_signage_reference.json
ThaiLife/Resources/Attributions/loopless-signage-assets.md
```

## 音频规范

- 单字可以复用发音正确的既有标准单字 MP3；缺失时生成真正的 MP3。
- `ลดราคา`、`เปิด`、`ปิด`、`ยา`、`ทางออก`、`ทางเข้า`、`จ่าย` 等场景词优先复用既有完整词 `audioID`；不存在的 `ชานม` 必须生成专用完整词 MP3。
- 所有播放走 `AudioPlaybackService.play(audioID:thaiText:)`。
- 新增或更新音频时，遵守项目规定的 Google Cloud TTS、MP3 容器校验、manifest 与原子替换流程。

## 验收标准

1. 课程页的专项扩展区域有「泰国招牌无头字对照」入口，点击后直接进入单张长页。
2. 页面没有目录、章节、查询框、测试、答案、评分、进度、FSRS 或复习卡行为。
3. 离线真机上，Sarabun 标准字与 Prompt 无头字的对照明显、稳定可见。
4. 高频字形、少量易混提示与五类真实招牌场景均完整可浏览。
5. 点击单字播放单字发音；点击多字场景词播放完整词音频。
6. 图片、字体、内容 JSON、音频和 Bundle 引用均有资源校验；每个字体与图片有可审计许可记录。
7. Simulator 全量测试与已连接真机构建、安装、启动通过。
