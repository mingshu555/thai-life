# 泰国常见菜单列表页与全局收藏设计

## 背景

“泰国常见菜单”目前直接进入整卡浏览页。需要先进入一个参考“分类课程”实现的列表页，并支持收藏。菜单卡片的收藏还必须出现在现有“收藏练习”页面中。

## 目标

1. Catalog 中点击“泰国常见菜单”后进入菜单列表页。
2. 菜单列表按现有 `UnitDetailView` 的交互模式展示，支持点击条目进入菜单整卡浏览。
3. 菜单条目可收藏/取消收藏，状态持久化到现有 `StudyStore`。
4. 现有“收藏练习”页面同时展示普通课程内容和菜单卡片收藏。
5. 从收藏练习点击菜单收藏时，进入现有 `ThaiMenuBrowserView`，并从对应卡片开始浏览。
6. 不改变已有菜单整卡 3D 翻转、左右滑动和课程收藏行为。

## 非目标

- 不把菜单卡片转换成 `ContentItem`。
- 不新增独立菜单收藏数据库表。
- 不改变现有 ReviewSession 的普通课程复习队列和评分逻辑。
- 不重做菜单卡片视觉设计。

## 方案

沿用现有 `FavoriteRecord.contentID` 作为统一收藏索引：

- 普通课程继续使用 `ContentItem.id`。
- 菜单卡片使用 `ThaiMenuCard.id`。
- `ThaiMenuListView` 读取 `ThaiMenuReference.cards`，通过 `StudyStore.allFavoriteIDs()` 显示收藏状态，并调用 `toggleFavorite(contentID:)`。
- `FavoriteListView` 加载课程内容和菜单参考数据，将收藏 ID 解析为两类展示条目。课程条目继续使用现有浏览路由；菜单条目使用菜单浏览路由。

为避免将菜单卡片伪装成普通课程，收藏列表使用一个本地展示抽象（普通课程/菜单卡片两种 case），而不修改持久化模型。

## 页面与导航

### Catalog

将“泰国常见菜单”的目标从 `ThaiMenuBrowserView` 改为 `ThaiMenuListView`，并注入 `appState`。

### ThaiMenuListView

- `List` + `.listStyle(.plain)`，整体风格参考 `UnitDetailView`。
- 可按 `category` 分组；每组使用菜单数据中的分类标题。
- 行内容至少包含泰语、中文释义和心形收藏按钮；如已有可复用资源，可显示图片缩略图。
- 点击行（心形按钮除外）设置待浏览菜单 ID，并导航到 `ThaiMenuBrowserView`。
- 菜单浏览页接收起始卡片 ID，初始化 `index` 到对应卡片。
- 收藏失败通过现有页面 alert 呈现。

### ThaiMenuBrowserView

保留现有卡片翻转和滑动逻辑，新增可选 `startCardID`（或等价初始化参数）：

- 无起始 ID 时从第一张卡开始，保持现有调用兼容。
- 有起始 ID 时从匹配卡片开始；找不到时回退到第一张。

### FavoriteListView

- 继续使用现有“收藏练习”标题和空态。
- 保留普通课程收藏的日期分组行为。
- 增加菜单收藏展示，菜单收藏按其 `favoritedAt` 与普通收藏共同参与日期分组（若现有展示抽象不适合混合，则至少在同一页面追加菜单收藏分组，不能丢失日期信息）。
- 普通课程行保留播放、浏览、取消收藏。
- 菜单行提供浏览和取消收藏，不调用普通课程音频/复习逻辑；浏览跳转到菜单卡片页。
- 取消收藏后立即更新本地展示状态。

## 数据与错误处理

- 菜单数据读取统一使用 `ContentRepository.loadThaiMenuReference()`。
- 收藏服务不可用、菜单资源读取失败、收藏操作失败时，沿用现有错误提示模式。
- 对无法解析的收藏 ID不崩溃：普通课程/菜单都找不到时忽略该记录，保留现有有效收藏显示。
- 菜单收藏 ID 必须与 `ThaiMenuCard.id` 稳定一致。

## 验收标准

- 点击 Catalog 的“泰国常见菜单”先看到列表，而不是直接看到卡片。
- 列表行点击进入菜单卡片浏览，并从所选卡开始。
- 收藏/取消收藏在菜单列表刷新后状态正确。
- 菜单收藏出现在“收藏练习”中；点击后进入对应菜单卡片。
- 普通课程收藏行为、课程浏览路由和已有菜单翻转行为无回归。
- 相关单元测试覆盖：菜单列表导航起始卡、菜单收藏切换、收藏列表混合解析及无效 ID 忽略。
