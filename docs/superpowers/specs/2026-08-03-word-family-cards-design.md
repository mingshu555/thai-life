# Word Family Cards Design (词根组词卡片设计)

## Goal

Provide structured **Root Expansion Cards (词根/前缀组词卡片)** in `ThaiLife`, grouping high-frequency words derived from a single root/prefix (e.g. `ไม่` "不", `น้ำ` "水", `รถ` "车", `ห้อง` "房间", `วัน` "日/天", `ใบ` "单/张") into a single card view. Learners can see the root definition and scan a multi-column table of derived words with audio playback for each word.

## Design Requirements & Aesthetics

1. **Card Structure**:
   - **Front**: Prominently displays the root word (e.g., `ไม่` / mài / 不), indicating it's a root card with total derived word count.
   - **Back**:
     - Root Summary Header (Root Thai + Romanization + Meaning + Usage Note).
     - **Vocabulary Table**: A vertical list where each row has 3 columns:
       - **Thai Word**: Rendered inside a rounded border pill tag. Tapping plays word audio.
       - **Romanization**: Accurate pinyin/romanization with tone marks.
       - **Chinese Meaning**: Natural Chinese translation decorated with a colored accent underline.
2. **Audio Interactivity**:
   - Tapping any Thai word pill in the table triggers audio via `AudioPlaybackService.play(audioID:thaiText:)`.
   - Front root tap plays the main root audio.
3. **Data Integration**:
   - `WordFamily` data model in Swift (`Domain/WordFamilyModels.swift`).
   - Content repository loads bundled `word_families.json` generated by `tools/generate_word_families.py`.
4. **App UI Integration**:
   - A dedicated Root Word Family Card View (`WordFamilyCardView.swift`).
   - Integrated into `Catalog` / `UnitDetailView` as a "词根词族" browser / study section.
