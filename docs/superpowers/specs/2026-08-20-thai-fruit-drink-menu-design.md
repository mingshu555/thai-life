# 泰国常见水果、饮料与菜单卡片设计

**日期：** 2026-08-20
**状态：** 已完成设计，待用户审阅后进入实施

## 背景

现有「饮食与点餐」分类已有点餐句型、餐厅沟通、部分食物、茶、咖啡和果汁内容，但缺少具体的泰国常见水果词，饮料词也不完整。

同时需要增加独立专项扩展「泰国常见菜单」，帮助用户在学习和旅行前认识泰国常见菜名。该专项扩展不是无头字课程，也不使用 Prompt 字体；它是正常泰语菜单学习卡片，重点是图片、菜名、中文意思和背面词语拆解。

## 目标

1. 在现有 `food_dining` 内容中加入泰国常见水果词。
2. 在现有 `food_dining` 内容中补充常见饮料词。
3. 为新增词提供自然、完整的泰语例句和中文整句翻译，并纳入现有音频和内容校验流程。
4. 在课程页专项扩展中增加「泰国常见菜单」入口。
5. 将菜单扩展实现为一组菜单卡片，**一道菜一张卡片**。
6. 每张卡片正面展示菜品图片、正常泰语菜名和中文菜名。
7. 每张卡片背面展示完整菜名和词语拆解，包括词块、中文释义和整体意思。
8. 菜名支持点击播放完整泰语词音频。
9. 图片作者、来源、许可证和 checksum 只保存在项目内部资源归属文档中，不在 App 页面展示。

## 非目标

- 菜单扩展与「泰国招牌无头字对照」完全独立，不共享 Prompt 无头字展示逻辑，也不把无头字内容放进菜单卡片。
- 菜单卡片不使用 Prompt 字体；使用 App 现有正常泰语字体/标准泰语显示方式。
- 不增加点餐注意事项、过敏提示、辣度、含猪肉/虾/花生等标签。
- 不展示作者、来源、许可证、版权说明或资源审计信息给 App 用户。
- 不创建菜单课程目录、章节、测试、答题、评分、FSRS 复习、进度或错题。
- 不把菜单图鉴内容硬塞进普通 `ContentItem`；菜单页面使用独立数据资源。
- 不使用 AI 生图；不使用来源不明、无法证明可离线再分发的网络图片。
- 不修改现有非饮食分类、收藏逻辑和日常复习行为。

## 一、饮食与点餐内容扩充

### 新增水果词

至少加入以下常见水果：

| 泰语 | 中文 |
|---|---|
| `มะม่วง` | 芒果 |
| `ทุเรียน` | 榴莲 |
| `มังคุด` | 山竹 |
| `เงาะ` | 红毛丹 |
| `มะพร้าว` | 椰子 |
| `แตงโม` | 西瓜 |
| `สับปะรด` | 菠萝 |
| `ลำไย` | 龙眼 |
| `กล้วย` | 香蕉 |
| `ส้ม` | 橙子／橘子 |

若内容包已有同一泰语词，应复用或修正现有条目，不创建重复内容。

### 新增饮料词

至少加入以下常见饮料：

| 泰语 | 中文 |
|---|---|
| `ชาไทย` | 泰奶／泰式奶茶 |
| `น้ำมะพร้าว` | 椰子水 |
| `น้ำเปล่า` | 白水 |
| `น้ำอัดลม` | 汽水 |
| `น้ำแข็ง` | 冰／冰块 |
| `นมเย็น` | 泰式粉红奶 |
| `โกโก้` | 可可 |
| `น้ำชา` | 茶水 |

已有 `ชา`、`กาแฟ`、`น้ำผลไม้` 等词保留；新增内容应避免重复 ID 和重复泰语词。

### 词卡与例句规则

- 水果、饮料作为普通 `ContentItem` 进入 `food_dining`，可参与现有课程浏览、收藏和 FSRS 逻辑。
- 每个新增词包含自然中文整句例句翻译；禁止使用逐词 gloss 拼接 `exampleMeaning`。
- 例句音频使用 `主音频ID-example.mp3`，由现有完整句音频管线生成。
- 主词点击播放主词音频；例句点击播放完整例句音频。
- 新增内容必须经过现有内容 manifest、checksum、音频 manifest 和格式校验。

## 二、专项扩展：泰国常见菜单

### 入口

在课程页「专项扩展」区域加入：

```text
泰国常见菜单
饭面、汤咖喱、小吃、水果与饮料
一道菜一张卡片 · 背面词语拆解
```

点击后直接进入 `ThaiMenuBrowserView`，不经过目录页或章节页。

### 页面形式

- 使用现有卡片浏览风格；
- 一道菜一张卡片；
- 支持点击翻面；
- 支持左右滑动切换下一道菜；
- 可显示当前位置，例如 `3 / 24`；
- 支持返回课程页；
- 离线可用；
- 不提供搜索框、测试、答案、进度、评分或复习按钮；
- 不进入 FSRS，不写复习日志，不保存学习草稿。

### 卡片正面：整体认识

正面固定展示：

```text
[一道菜的真实图片]

ผัดไทย
泰式炒粉

[播放完整菜名]
```

规则：

- 每张卡只有一道菜或一个菜单词；
- 使用 App 现有正常泰语字体，不使用 Prompt 无头字体；
- 泰语菜名显示标准写法；
- 显示自然中文菜名；
- 点击泰语菜名或播放按钮播放完整菜名音频；
- 正面不显示详细词块拆解，先建立图片、泰语和中文的整体对应。

### 卡片背面：词语拆解

背面固定展示：

```text
ผัดไทย
泰式炒粉

词语拆解
ผัด    炒／翻炒
ไทย    泰国的

整体：泰式炒粉
[播放完整菜名]
```

规则：

- 显示完整泰语菜名和中文意思；
- 显示组合层词块拆解；
- 每个词块有自然中文释义；
- 菜名适合时提供最小词级拆解；
- 拆解只用于视觉理解，不单独播放词块音频；
- 播放仍然使用完整菜名音频；
- 禁止从词块 gloss 拼接整体中文意思。

### 菜单分类与内容

固定包含以下分类，分类只作为卡片上的小标签或浏览顺序，不创建独立目录页：

1. **米饭与面食**
   - `ผัดไทย`：泰式炒粉
   - `ข้าวผัด`：炒饭
   - `ผัดกะเพรา`：打抛饭
   - `ข้าวมันไก่`：海南鸡饭
   - `ก๋วยเตี๋ยว`：泰式米粉／面

2. **汤与咖喱**
   - `ต้มยำกุ้ง`：冬阴功虾汤
   - `ต้มข่าไก่`：椰奶鸡汤
   - `แกงเขียวหวาน`：绿咖喱
   - `แกงมัสมั่น`：玛莎曼咖喱

3. **烧烤与小吃**
   - `หมูปิ้ง`：烤猪肉串
   - `ไก่ย่าง`：烤鸡
   - `ส้มตำ`：青木瓜沙拉
   - `ปอเปี๊ยะทอด`：炸春卷
   - `โรตี`：泰式煎饼／印度飞饼

4. **水果**
   - `มะม่วง`：芒果
   - `ทุเรียน`：榴莲
   - `มังคุด`：山竹
   - `เงาะ`：红毛丹
   - `มะพร้าว`：椰子
   - `แตงโม`：西瓜
   - `สับปะรด`：菠萝
   - `ลำไย`：龙眼

5. **饮料与甜品**
   - `ชาไทย`：泰奶／泰式奶茶
   - `กาแฟ`：咖啡
   - `น้ำมะพร้าว`：椰子水
   - `น้ำผลไม้`：果汁
   - `ข้าวเหนียวมะม่วง`：芒果糯米饭
   - `ไอศกรีม`：冰淇淋

### 图片资源与标注

- 每道菜卡片优先使用一张真实菜品图片；
- 可使用一张包含多个菜品的开放许可合图，但进入卡片后，每张卡只裁切或聚焦其中一道菜；
- 图片上可以有项目制作的泰语菜名标签，但标签只显示菜名，不显示点餐注意事项或版权信息；
- 菜卡下方和背面继续显示标准泰语文本、中文意思和拆解；
- 一张合图可服务多个卡片，但每个卡片的主图必须清楚指向当前菜品。

### 图片来源规则

- 优先从 Wikimedia Commons 等明确开放许可来源寻找真实图片；
- 每张最终图片在项目内部归属文档记录：作者、原始来源、许可证、获取日期、文件 checksum；
- 归属文档路径：

```text
ThaiLife/Resources/Attributions/thai-menu-assets.md
```

- 归属文档不展示在 App 用户界面；如随 Bundle 打包，仅用于项目审计；
- 图片必须复制为离线 Bundle 资源，不运行时联网加载；
- 无法证明 iOS App 离线再分发许可的图片必须替换；
- 不使用 AI 生成菜品图片。

## 三、独立菜单数据模型

新增独立资源：

```text
ThaiLife/Resources/Content/thai_menu_reference.json
```

模型应支持正面、背面和拆解：

```text
ThaiMenuReference
- introductionZhHans
- cards: [ThaiMenuCard]

ThaiMenuCard
- id
- category
- thai
- meaningZhHans
- audioID
- imageAssetID
- breakdown: ThaiMenuBreakdown

ThaiMenuBreakdown
- combinations: [ThaiMenuBreakdownPart]
- minimal: [ThaiMenuBreakdownPart]

ThaiMenuBreakdownPart
- thai
- glossZhHans
```

`ThaiMenuCard.audioID` 必须指向完整菜名音频；不复用不相关词条音频。若某道菜没有现成音频，新增完整菜名 MP3。

## 四、验证与验收

### 内容验证

- 新增水果/饮料无重复泰语词和重复 ID，分类正确为 `food_dining`；
- 所有新增例句和 `exampleMeaning` 成对存在，中文为自然整句翻译；
- 菜单 JSON 的卡片、拆解、图片 ID、音频 ID 全部非空且引用有效；
- 每张菜单卡至少有一张图片和一组非空拆解；
- 菜名及组合拆解的泰语按顺序可重建完整菜名；
- 每个拆解词块有自然中文释义；
- 图片归属文档覆盖每张随包图片，但不在 UI 展示。

### UI 验收

1. 课程页可以直接进入「泰国常见菜单」卡片浏览；
2. 每张卡只显示一道菜；
3. 正面显示图片、标准泰语菜名和中文菜名；
4. 翻到背面显示完整菜名、中文意思和词语拆解；
5. 左右滑动可以切换菜品；
6. 点击菜单词播放完整泰语菜名音频；
7. 页面没有搜索、测试、答案、点餐注意事项或 FSRS 行为；
8. 饮食与点餐普通课程可浏览新增水果和饮料词。
