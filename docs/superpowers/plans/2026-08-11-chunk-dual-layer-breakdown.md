# Chunk Dual-Layer Breakdown Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give each of the 215 course `chunk` cards a curated combination-level and minimal-word-level Thai breakdown, and always display both layers on the course-browser and review-card answer sides.

**Architecture:** Add a `ChunkBreakdown` value to the content domain while retaining `segments` exclusively for existing example/headword visual segmentation. A new reviewed JSON source is validated and overlaid by `tools/generate_content.py`; Python plus Swift validators enforce complete chunk coverage and exact Thai reconstruction. A shared SwiftUI presentation/view supplies the two sections to `CardBack`, which is used by both course browsing and normal review.

**Tech Stack:** Swift 5.10, SwiftUI, XCTest, Python 3.10 standard library, XcodeGen, JSON resources, CryptoKit SHA-256 manifest validation.

## Global Constraints

- There are exactly 1,200 content items and exactly 215 `kind == "chunk"` items.
- `segments` continues to mean visual segmentation of the complete `example` when an example exists; do not repurpose it for chunk breakdowns.
- Every chunk must include non-empty `combinations` and `minimal` arrays; concatenating either array's Thai text, after stripping whitespace, must equal `ContentItem.thai` after stripping whitespace.
- Every non-chunk must omit `chunkBreakdown`.
- Display both breakdown layers permanently expanded only in course-browser and review answer cards; do not add breakdowns to course-list rows.
- Complete Thai text uses the existing `audioID` and the existing main-word playback path. Do not add segment audio or change sentence/example playback behavior.
- `items.json` and `content-manifest.json` are generated artifacts. Always write them with `python3 tools/generate_content.py`, never edit them directly.
- Preserve the existing content checksum verification; a generated manifest checksum must match the exact `items.json` bytes.
- Do not modify audio resources or audio-generation behavior.

```swift
let normalizedThai = item.thai.replacingOccurrences(of: " ", with: "")
if item.kind == .chunk {
    guard let breakdown = item.chunkBreakdown else {
        errors.append(.missingChunkBreakdown(id: item.id))
        continue
    }
    for (layer, segments) in [("combinations", breakdown.combinations), ("minimal", breakdown.minimal)] {
        guard !segments.isEmpty, segments.allSatisfy({ !$0.thai.trimmingCharacters(in: .whitespacesAndNewlines).isEmpty && !$0.gloss.trimmingCharacters(in: .whitespacesAndNewlines).isEmpty }) else {
            errors.append(.emptyChunkBreakdown(id: item.id, layer: layer))
            continue
        }
        let reconstructed = segments.map(\.thai).joined()
        if reconstructed.replacingOccurrences(of: " ", with: "") != normalizedThai {
            errors.append(.chunkBreakdownReconstructionFailed(id: item.id, layer: layer, expected: item.thai, got: reconstructed))
        }
    }
} else if item.chunkBreakdown != nil {
    errors.append(.unexpectedChunkBreakdown(id: item.id))
}
```

```swift
import SwiftUI

struct ChunkBreakdownSection: Equatable {
    let title: String
    let segments: [PhraseSegment]
}

enum ChunkBreakdownPresentation {
    static func sections(for item: ContentItem) -> [ChunkBreakdownSection] {
        guard item.kind == .chunk, let breakdown = item.chunkBreakdown else { return [] }
        return [
            ChunkBreakdownSection(title: "组合拆解", segments: breakdown.combinations),
            ChunkBreakdownSection(title: "最小拆解", segments: breakdown.minimal),
        ]
    }
}

struct ChunkBreakdownView: View {
    let item: ContentItem

    var body: some View {
        VStack(alignment: .leading, spacing: 16) {
            ForEach(Array(ChunkBreakdownPresentation.sections(for: item).enumerated()), id: \.offset) { _, section in
                VStack(alignment: .leading, spacing: 8) {
                    Text(section.title)
                        .font(.system(size: ReviewCardTypography.sectionLabelFontSize, weight: .bold))
                        .foregroundColor(ThaiLifeTheme.textTertiary)
                    ForEach(Array(section.segments.enumerated()), id: \.offset) { _, segment in
                        HStack(alignment: .firstTextBaseline, spacing: 8) {
                            Text(segment.thai)
                                .font(.system(size: ReviewCardTypography.segmentThaiFontSize, weight: .bold))
                                .foregroundColor(ThaiLifeTheme.deepGreen)
                            Text(segment.gloss)
                                .font(.system(size: ReviewCardTypography.segmentGlossFontSize))
                                .foregroundColor(ThaiLifeTheme.textTertiary)
                        }
                    }
                }
            }
        }
    }
}
```
